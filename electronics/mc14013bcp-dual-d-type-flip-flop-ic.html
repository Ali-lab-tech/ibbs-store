Description Marked "MC14013BCP" on the package with Motorola's logo, this is Motorola's (now ON Semiconductor) MC14013BCP , a CMOS Dual D-Type Flip-Flop integrated circuit (part of the standard 4000 CMOS series, functionally equivalent to CD4013). Each flip-flop has independent Data (D), Clock (CLK), Set (S), and Reset (R) inputs, along with complementary outputs ( $Q$ and $\bar{Q}$ ). Logic states on the Data input are transferred to the $Q$ output on the positive-going edge of the clock pulse. Independent asynchronous Set and Reset inputs allow direct setting or clearing of the flip-flops regardless of the clock state.
