Description Marked "80R430FE3" on the package with the Silan ("SL") logo, this is Hangzhou Silan Microelectronics' SVS80R430FE3, confirmed directly against Silan's own official datasheet (part of the SVS80R430F(FJH)(D)(FJD)(L8A)(S)E3 family). Silan's own ordering table confirms the marking "80R430FE3" corresponds to part SVS80R430FE3, packaged halogen-free in a tube — an exact match to your part. The naming follows Silan's standard convention where the numeric code indicates rated voltage and typical on-resistance (800V class, ~430mΩ RDS(ON)). This is a super junction MOSFET, meaning it uses an advanced charge-balance cell structure to achieve significantly lower on-resistance for a given voltage rating compared to conventional planar MOSFETs — well suited for high-voltage offline switching applications where efficiency and low conduction loss matter.
