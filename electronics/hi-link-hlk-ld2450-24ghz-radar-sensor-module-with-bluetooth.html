Product details

This sensor serves as a replacement for a PIR sensor and works on the basis of microwaves and the doppler effect. Due to a difference in speed, this sensor can detect motion, this also works through almost all materials except metal. The sensor status can be read via the UART interface or via Bluetooth to read out more information such as detection distance. The sensor can be used in different ways: You can use the sensor with ESPHome via the following library: ESPHome Hi-Link HKL-LD2450 You can configure and update this sensor via the HLKRadarTool app on Android/iOS. You can read the sensor with a microcontroller such as an Arduino via the following library: arduino-lib_HLK-LD2450_Radar See the following page for more information: Drive Check the tab "Downloads" for more information and/or downloads.
