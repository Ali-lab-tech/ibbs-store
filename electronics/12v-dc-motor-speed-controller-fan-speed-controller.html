Product details

This is 12v dc motor speed controller or dimmer which is designed for precise control of interior accent lighting in your auto, truck, RV, boat or aircraft. With easy screw-down terminals, you can install this controller in minutes. Its PWM (pulse width modulation) design is the preferred method to control LED lighting for light strips, map lights, under panel, baggage or utility lighting. It supports up to 60 Watts so you can use this controller for many dc load dimming applications. Easy to install and use - ideal for many different applications. Specifications of 12v dc motor speed controller : Operating voltage: DC7V-20V Output current: 0-5A Output power: 60W (max) PWM duty cycle: 1% -100% Size: 30mm x 24mm x 15mm (Without Handle)
