Product details

This 4 USB buck fast-charging module integrates the common 5V charging recognition function, which is compatible with 99% of the mobile phones on the market. Compared with products without charging recognition function, this module can save a lot of charging time by triggering the peak current via fast charging protocol. It features 6~32V input and 3~12V output(default 5V). The voltage can be changed through fast-charging decoy. Multiple fast-charging protocols are supported and all 4 channels work independently. With steady output, this Fast Charge Module is able to work for a long time without voltage shift. It can be suitable for projects like mobile phone fast charging, Car charging retrofit, solar charger, DIY power source, etc. FEATURES 4 USB output Support multiple fast-charging protocols Can be used as charger and power supply SPECIFICATION Input Voltage Range: 6V-32V Output Voltage: 3-12V, automatically adjust according to the fast-charge protocol (the default output is 5V, input should be 2V higher than output) Output Current: 0-3A Output power: ≤24W (5V@3.4A, 9V@2.5A, 12V@2A, etc.) Chip Protection: input over-voltage, under-voltage protection, input over-current protection, output over-current, short-circuit protection, over-temperature of the whole machine protection Fast-charging Protocol: Support DCP protocol, BC1.2, Apple, Samsung protocol Support Huawei fast-charging protocol FCP/SCP, AFC Support Spreadtrum fast-charging protocol SFCP Support Qualcomm QC2.0 and 3.0 Support MTKPE1.1/PE2.0 SHIPPING LIST 4-way Fast Charge Buck Module x1
