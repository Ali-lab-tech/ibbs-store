Description Marked "ICE3BR1765J" on the package with Infineon's logo, this is Infineon's ICE3BR1765J , an off-line Switched-Mode Power Supply (SMPS) current-mode PWM controller with an integrated 650V CoolMOS® MOSFET (part of the CoolSET® F3R series). Designed for high-efficiency flyback converters, it integrates both the high-voltage power switch and the controller circuit into a single DIP-8 package. It features built-in frequency jittering to lower EMI noise, Active Burst Mode for ultra-low standby power consumption, and comprehensive protection mechanisms (overload, open-loop, over-temperature, and over-voltage) with auto-restart capability. Key Specifications Type: Off-Line Current Mode PWM Controller with Integrated 650V CoolMOS® Manufacturer: Infineon Technologies Package Marking: ICE3BR1765J / H2305/S3E / PF2468597GU Package: PG-DIP-8 / PDIP-8 (8-pin dual in-line package) Drain-Source Breakdown Voltage ( $V_{DS}$ ): 650V $R_{DS(ON)}$ , max: $1.70\,\Omega$ at $T_J = 25^\circ\text{C}$ Switching Frequency: 65 kHz (fixed with built-in frequency jittering) Max Output Power ( $P_{OUT}$ ): ~26.5W (85–265 VAC) / up to 44.5W (230 VAC open frame) Supply Voltage ( $V_{CC}$ ): 10.5V to 25V ( $V_{CC}$ start-up threshold: 18V) Max Duty Cycle: 75% Operating Junction Temperature Range: $-40^\circ\text{C}$ to $+150^\circ\text{C}$ Common Applications Switch-Mode Power Supplies (SMPS) for TVs, set-top boxes, and monitors Auxiliary power supplies for home appliances and industrial controllers AC-DC power adapters, set-top box power, and chargers Low-standby-power off-line flyback converters Package Includes 1 x Infineon ICE3BR1765J Off-Line SMPS Controller IC (PG-DIP-8)
