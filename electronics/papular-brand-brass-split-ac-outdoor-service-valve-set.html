Product details

This Brass Split AC Outdoor Service Valve Set is designed for use in split air conditioning systems. These valves serve as the primary connection points for refrigerant lines, allowing technicians to isolate the outdoor unit for maintenance, pressure testing, or refrigerant recovery. Features of this service valve set include: Durable brass construction for corrosion resistance. Designed for reliable sealing in high-pressure HVAC applications. Standard configuration for compatibility with common split AC outdoor units.
