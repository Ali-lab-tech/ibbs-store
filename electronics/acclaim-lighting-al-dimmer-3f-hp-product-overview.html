Product details

Congratulations with your purchase of this product. Read this manual carefully before using our AL-DIMMER-3F HP. The AL-DIMMER-3F HP, a multifunction LED dimmer with 3 channels, is designed to set the intensity for the high power RGB LEDs. FEATURES: The three faders can separately control the relevant channel value. The current output is available in 350mA and 700mA for option. Available in online operation and DMX control for slave control, Auto and Manual mode are for master control. In online operation mode, the master can drive up to 32pcs slave AL-DIMMER-3F HP. Infrared remote control. Working mode and DMX address can be set by Dip-switch. SPECIFICATIONS: Power Requirement: 12~24VDC, 6.5A Max Output Current: 6A/CH max., Total 6A max IR In : External Infrared Remote sensor port DC In : 4-pin terminal DMX In/Out : 3-pin terminal Loading Out : 4-pin terminal Housing : Black plastic Control Protocol : DMX-512 (1990) Connection : Terminal Listing : CE certified PACKAGE INCLUDE: 1xAcclaim Lighting AL Dimmer 3F HP
