Description The 74HC153 is a Dual 4-Input Multiplexer IC built on high-speed CMOS (HC) logic technology, housed in a standard through-hole DIP package. The device features independent enable inputs (nE) and common data select inputs (S0 and S1). For each multiplexer, the select inputs select one of the four binary inputs and route it to the multiplexer output (nY). A HIGH on the enable input (E) forces the corresponding multiplexer output LOW, giving straightforward control over each section independently. Inputs include clamp diodes, which enable the use of current limiting resistors to interface inputs to voltages in excess of VCC, adding flexibility when working with mixed-voltage systems. The device offers non-inverting outputs, along with a separate enable input for each output alongside common select inputs, and complies with JEDEC standard no. 7A. With two independent 4-input multiplexer sections on a single chip, the 74HC153 is a compact solution for selecting and routing one of several data lines to a single output — a common requirement in bus multiplexing, data selection, control logic, and digital signal routing circuits. It's specified for operation from -40°C to +85°C and -40°C to +125°C, making it suitable for both general-purpose and more demanding temperature environments. Common Applications Data selection and bus multiplexing in digital systems Signal routing where two channels of 4-to-1 selection are needed Boolean function generation (can implement logic functions via multiplexer configuration) General combinational logic design and control circuits Package Includes 1 x 74HC153 Dual 4-Input Multiplexer IC
