Product details

The Smart Card Reader and Writer, Recorder RFID IC Copier, NFC Duplicator (13.56 MHz) reads, writes, records, and duplicates data from RFID and NFC cards. It is useful for security, access control, and data management. Key Features Supports 13.56 MHz (High Frequency - HF) cards Compatible with IC cards, proximity cards, smartcards Supports MIFARE Classic, Ultralight, DESFire, ISO14443A/B cards Reads serial numbers and encrypted data Writes new data to blank cards Duplicates cards by copying data to blank cards LCD display shows card type, frequency, and data Easy operation with buttons or touchscreen Internal memory for temporary data storage Compact, handheld, and rechargeable via USB USB connection to PC for data transfer and updates Supports basic RFID/NFC data encryption Applications Access control systems Public transportation cards Security auditing Personal card backups Use Cases Security professionals Hobbyists and technicians Use responsibly and respect card ownership and privacy laws. Package Contents 1 x Card Reader 1 x Cable
