Product details

28 Pin Wide IC Socket base adaptor is a 28 pin IC holder, which can be soldered directly onto the PCB. The IC can be removed from this socket when required. The IC is placed on the socket at the time of use. This base acts as a removable IC holder. The IC base is for a wide IC. The socket is used when the IC is temperature sensitive and the heat from the soldering iron can damage the IC. This socket is used when working with a microcontroller IC and can be removed for programming. Features: 28 pins. JDEC compliant. Molded notch for proper orientation. Easy to insert and remove ICs. Package Included: 1 x 28 Pin Wide DIP IC Socket Base Adaptor
