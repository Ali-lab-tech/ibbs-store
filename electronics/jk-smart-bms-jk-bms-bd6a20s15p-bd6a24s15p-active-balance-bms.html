Product details

Description Battery charge controller with support from 8 to 20 cells, load/charge current 150A and at peak up to 300A, balance current 0.6A. The JK-BMS BD6A20S15P board has a built-in Bluetooth module for connecting from a phone, an Android / iOS app is provided for free, and it also allows you to connect an LCD screen. Technical characteristics of the BMS board BD6A20S15P : Number of cells 8S-20S LiFePo4 or 7S-20S Li-Ion or 12S-20S LTO Load/charge current 150A / 300A (pik) Active balancer current 0,6A Interface support RS-485, CAN, Bluetooth JK-BMS connection principle: The battery is connected to wire B- and the load to P- A separate loop with red wires is used to balance each cell separately A button with a built-in LED that lights up when the SMART JK BMS is turned on Two temperature sensors that allow you to safely control the temperature, and when it exceeds the set limits, the BMS board will turn off Additionally, you can connect the BMS controller to the RS485, CAN interfaces for remote monitoring and control. The Jikong BMS controller supports LiFePo4, Li-Ion, LTO batteries. BMS board kit: BMS Jikong board Cable for balancing cells 45 cm long On/off button with LED Two temperature sensors Specifications Number of cells LiFePo4 (Lithium iron phosphate) 8S-20S Li-Ion (Lithium-ion) 7S-20S LTO (Lithium titanate battery) 12S-20S
