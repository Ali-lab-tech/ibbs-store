Product details

The TM1637 4 Bits Digital Tube LED Display Module is an affordable solution for displaying the output data of your Arduino project. Though the data displayed is restricted by numbers still it allows users to display some characters too like A, B, C etc. This 7 segment LED Display has 4 digits which are controlled by TM1637 Driver Chip. It requires only two connections to control this TM1637 4 Bits Digital Tube LED Display Module. Also thanks to the I2C Bus you can control it using only 2 wires, leaving more pins available on your MicroController to connect other things. The module is a 12-foot clock with four common anode tube (0.36 inch) display module for driver IC TM1637, only two signal lines can make the MCU control four 7-segment digital tubes. There are several modules using this TM1637 chip to form a 4 digit numerical display module. TM1637 has also keyboard input capability but is not used in this module.
