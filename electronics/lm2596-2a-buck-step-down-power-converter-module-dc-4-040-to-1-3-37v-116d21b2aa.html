Technical Specifications Parameter Specification Model LM2596 adjustable DC-DC buck converter Converter Type Step-down voltage regulator Input Voltage 4–40V DC Adjustable Output Voltage 1.3–37V DC; output must be lower than input Output Current Up to 2A, depending on voltage difference, temperature and cooling Voltage Adjustment Multi-turn potentiometer for precise adjustment Display Built-in digital LED voltmeter Voltage Monitoring Selectable input or output voltage display Indicators “IN” and “OUT” LEDs identify the displayed voltage Calibration Input and output voltmeter readings can be calibrated using the onboard buttons Memory Function Retains the last selected voltage display mode after power-off Connections Screw terminals and solder connection points Package Includes 1 × LM2596 2A step-down converter module with LED voltmeter Operating Note: This module reduces DC voltage only. Adjust and verify the output voltage before connecting your device. Additional cooling may be required at higher loads. Output voltage calibration steps: Step 1: Adjust the right button so that “OUT” LED lighted, the voltmeter shows the value of output voltage; Press the right button for more than 2 seconds, release, voltmeter and “OUT” LED flashes in synchronization so that you enter the output voltage calibration mode. Step 2: Press the right button (normal speed), the voltage value is adding up a unit; Press the left button, minus a unit; Due to a unit is less than 0.1V, the minimum voltage display to 0.1V, so you need to continuously press 1-5 times to see the voltmeter change 0.1V, how many times voltmeter change 0.1V by pressing the key, depending on the current display voltage, the higher the voltage, the fewer the number of press. Step 3: Press the right button for more than 2 seconds, release, to exit the output voltage calibration mode. All parameters set to automatically power down to save. Input voltage calibration steps: Step 1: Adjust the right button so that “IN” LED lighted, the voltmeter shows the value of input voltage; press the right button for more than 2 seconds, release, voltmeter and “IN” LED flashes in synchronization so that you enter the input voltage calibration mode.
