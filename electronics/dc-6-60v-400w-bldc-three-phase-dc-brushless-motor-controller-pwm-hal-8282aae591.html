350W/400W Brushless Hall DC Motor Driver - ZS-X11H V2 High-performance DC three-phase brushless control board designed for precise motor control with Hall sensor feedback. This newly upgraded BLDC wide voltage controller supports PLC 0-5V analog control and PWM control for versatile speed regulation. Technical Specifications: Working Voltage: 6-60V DC (limit 60V with margin for safe use) Working Current: Rated 16A, Peak 20A Power Output: Rated 200-300W, Maximum 350-450W (with enhanced heat dissipation) Overcurrent Protection: Yes Product Size: 63mm × 45mm × 31mm (L × W × H) Net Weight: Approximately 77-93g (including thread) Material: Metal + Plastic Process: Full SMT patch process for stable performance Interface Description: MA, MB, MC: Motor phase line output (connect to motor) VCC, GND: Main power supply (external DC power supply) 5V, GND: Onboard 5V power supply (current ≤30-50mA) Ha, Hb, Hc, +5V, GND: Hall signal power input interface (5-wire connection) DIR: Direction control - forward/reverse (low level effective, can connect external switch to ground) STOP: Stop control interface (low level effective) Brake: Brake control (high level effective, 25V-50V high voltage for strong braking force) Speed Regulation: Integrated potentiometer or external 0-5V analog/PWM dual signal input SC: Speed pulse output interface (reserved, no technical support) P: PWM signal input (Amplitude: 2.5-5V, Frequency: 50Hz-20kHz best) Key Features: Wide voltage input range: DC 6-60V (compatible with 12V, 24V, 48V systems) Three-phase DC brushless motor control with 120° electrical angle PWM and PLC 0-5V analog control support Hall sensor feedback for accurate positioning and smooth operation Positive/reverse rotation control with external switch capability Integrated potentiometer for onboard speed regulation Overcurrent protection for safe operation Compact driver board with aluminum heat sink Low-speed stable start with high torque output Applications: Ideal for robotics, automation systems, electric vehicles, industrial machinery, CNC equipment, and DIY electronics projects requiring precise brushless motor control.
