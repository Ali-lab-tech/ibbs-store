Product details

4026 IC is a 4000 series IC . This CD4026 IC is a CMOS seven-segment counter IC and can be operated at very low power. This 16 dip ic is a decade counter, counts in decimal digits (0-9). CD4026 decade counter ic is used to display numbers on seven segment displays and it increments the number by one when a clock pulse is applied to its PIN 1. Means more the clock pulse rate, faster the numbers change in 7 Segment Display. Features Of CD4026 Decade Counter Divider IC DIP-16: Counter for 7-Segment display Can drive a common cathode 7-Segment display directly Easy to interface with a timer or micron rollers (TTL compatible) Can be easily cascaded with more IC to display the higher range of number Maximum Clock Frequency: 6Mhz Pin Configuration CD4026 Decade Counter 7 Segment Decoder IC: Clock (CLK) (1): The counting happens when this clock pulse goes high, this pin is normally connected to 555 timer or other uC to produce a pulse Clock Inhibit (INH) (2) : Connected to the Ground (low) of the circuit, to enable clock pin Enable Input (DEI) (3) : This pin is connected to +5V (high) to enable the output pins (Out A to Out G) Enable Output (DEO) (4) : This is an output which always stays high, this pin will be only if more than one CD4026 IC is used (cascaded) Divide by 10 (CO) (5) : This is the carryover output pin; it produces a pulse after counting till 9. This pin will be only if more than one CD4026 IC is used (cascaded) Out A,B,C,D,E, F,G (6,7,8,9,10,11,12,13) : These are the decoded output pins which should be connected to 7-Segment display. Ground: The ground pin should be connected to the ground of the circuit Not 2 out (UCS) (14) : This is Ungated C segment pin. This is an output pin which will be rarely used when division is required. Reset (15) : This input pin when made high (+5V) will reset the count to 0. Vcc (16) : This pin powers the IC, typically +5V is used.
