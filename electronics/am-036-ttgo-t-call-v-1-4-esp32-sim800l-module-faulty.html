Product details

The AM-036 LilyGO TTGO T-Call V1.4 combines an ESP32 microcontroller with a SIM800L cellular module into a single development board. This module allows microcontrollers to communicate over long distances using GSM/GPRS networks alongside short-range Wi-Fi and Bluetooth. Key Features Dual Microcontroller & Cellular Integration: Combines ESP32 processing power (Wi-Fi + Bluetooth 4.2 BLE) with SIM800L GSM/GPRS capabilities. USB Type-C Interface: Includes an onboard USB-to-UART bridge (CP2104 / CH9102) for programming and power delivery. Cellular Network Support: Enables SMS sending/receiving, voice call functionality, and 2G GPRS data transfer via a Nano-SIM card slot. Integrated Battery Management: Includes a 2-pin JST (1.25mm) connector and lithium battery charging IC (TP4056 or similar) to support portable power setups. Rich Peripheral I/O: Exposes standard ESP32 GPIOs for UART, SPI, I2C, PWM, ADC, and capacitive touch pins. Technical Specifications Specification Details Main Microcontroller ESP32-D0WDQ6 (240MHz Xtensa® 32-bit LX6 dual-core) Flash Memory / PSRAM 4MB QSPI Flash / 8MB PSRAM Cellular Module SIM800L (Quad-Band 850/900/1800/1900MHz) SIM Card Slot Nano-SIM Wireless Connectivity Wi-Fi 802.11 b/g/n + Bluetooth v4.2 BR/EDR & BLE Operating Voltage 2.7V – 3.6V (Board) / USB 5V 1A–2A recommended Onboard USB Port USB Type-C Battery Connector 2-Pin 1.25mm JST (3.7V Li-Po / Li-ion) Antenna Connections IPEX/U.FL connector for GSM antenna Typical Applications Remote IoT Telemetry: Collecting and pushing sensor data to cloud services in areas without Wi-Fi access. SMS Alert Systems: Security, home automation, or fault-detection alerts delivered directly to mobile phones. Vehicle & Asset Tracking: GPS/GSM tracking prototypes combined with external GPS sensors. Remote Control Switches: Controlling relays and hardware via SMS commands or HTTP/MQTT over GPRS. Package Includes: 1x AM-036 TTGO T-Call V 1.4 ESP32 + SIM800L Module (Faulty)
