Product details

The Jikong 3.2-inch LCD screen is a dedicated display accessory designed for JK Smart BMS units. This monitor provides a clear interface for users to track essential battery parameters directly from their battery management system. Key features include: 3.2-inch display screen for JK Smart BMS Real-time voltage monitoring Real-time current monitoring State of Charge (SOC) indicator Temperature monitoring Battery level indicator
