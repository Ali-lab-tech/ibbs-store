Build smarter. Build faster. The ESP32 2.8 Inch Capacitive Touch Display Development Board (ESP32-2432S028) puts a full graphical touchscreen interface in the palm of your hand — powered by the battle-tested ESP32 dual-core processor with built-in Wi-Fi and Bluetooth. Whether you're prototyping an industrial control panel, a smart home dashboard, or a wireless data monitor, this board gets you from idea to interactive UI without the clutter of external displays or extra wiring. Key Features ESP32 Dual-Core Xtensa LX6 processor for high-performance embedded computing 2.8" TFT LCD with 240×320 (QVGA) resolution — crisp and vibrant Capacitive touch panel for responsive, gesture-friendly interaction Built-in 2.4GHz Wi-Fi (802.11 b/g/n) and Bluetooth Classic + BLE High-speed SPI display interface for smooth rendering USB Type-C for power and programming 3.3V logic — compatible with standard ESP32 peripherals LVGL, Arduino IDE, ESP-IDF, and PlatformIO ready Compact all-in-one design with mounting holes Technical Specifications Specification Details Processor ESP32 Dual-Core Xtensa LX6 Wi-Fi 2.4GHz (IEEE 802.11 b/g/n) Bluetooth Classic + BLE Display Size 2.8 Inch Display Type TFT LCD Resolution 240 × 320 Pixels (QVGA) Touch Panel Capacitive Display Interface SPI USB Interface USB Type-C (revision dependent) Logic Voltage 3.3V Programming Arduino IDE, ESP-IDF, PlatformIO Graphics Library LVGL Supported GPIO & Interfaces The board exposes a full set of ESP32 programmable interfaces: GPIO, UART, SPI, I²C, PWM, ADC, DAC (variant-dependent) , I²S, and capacitive touch channels Exact GPIO mapping varies by board revision. Always refer to the manufacturer's pinout diagram before wiring peripherals.
