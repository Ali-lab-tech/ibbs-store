Product details

Upgrade or repair your RC rock crawler with the WPL BC V1 Main Board . Engineered specifically for the popular WPL (B-Series, C-Series) and MN Model series, this circuit board acts as the brain of your vehicle. It integrates multiple control systems into a single, compact black PCB, ensuring efficient power distribution and precise signal processing. Whether you are fixing a water-damaged board or building a kit version from scratch, this module offers plug-and-play compatibility with standard WPL connectors. It features dedicated ports for steering servos, brushed motors, battery input, and a full LED lighting system (headlights, turn signals, and brake lights). Key Features: All-in-One Integration: Combines a 2.4GHz Radio Receiver and Brushed ESC in one unit to save space. Intelligent Light Control: Features dedicated outputs for LED linkage, allowing for realistic turn signals and brake lights when driving. Stable Connection: Equipped with a shielded antenna wire for interference-free 2.4GHz signal reception. OEM Quality: The original spec board found in RTR (Ready-to-Run) versions of WPL trucks, ensuring 100% fitment and compatibility. Easy Installation: Standard JST and XH connectors allow for easy swapping without the need for complex soldering. Board Pinout / Interfaces: Power Input (Red Socket): For 7.4V (2S) Li-ion/LiPo Battery. Motor Output: 2-Pin connector for Brushed 130/180/260/370 motors. Servo Output: 3-Pin standard connector for Steering Servo. LED Outputs: Multiple small white sockets for Headlights and Taillights. Specifications Model: WPL BC V1 (Main Board) Input Voltage: 6V – 7.4V (Recommended for 2S Li-ion/LiPo) Frequency: 2.4GHz Board Color: Black Supported Motor Type: Brushed DC Compatibility: WPL Series: B1, B14, B16, B24, C14, C24, C34, C44 MN Series: D90, D91, D96, D99, MN90, MN99S JJRC: Q60, Q61 Material: Composite PCB with Electronic Components Package Includes: 1x WPL BC V1 Receiver Circuit Board
