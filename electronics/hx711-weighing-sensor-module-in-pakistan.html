Product details

The HX711 Dual-Channel 24 Bit Precision A/D weight Pressure Sensor Load Cell Amplifier and ADC Module is a small breakout board for the HX711 IC that allows you to easily read load cells to measure weight. The HX711 uses a two-wire interface (Clock and Data) for communication. The load cell amplifier module communicates with the host via the TTL 232. By connecting the module to your microcontroller you will be able to read the changes in the resistance of the load cell and with some calibration. You’ll be able to get very accurate weight measurements. This pressure sensor can be handy for creating your own industrial scale, process control, or simple presence detection. It is commonly used to measure force, pressure, tension, torque, acceleration, and displacement used in aviation, machinery, electricity, chemistry, construction, medicine, and many other areas.
