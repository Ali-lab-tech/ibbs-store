Product details

Description Marked "GBJ15J" on the package, this is a GBJ15J (often produced by manufacturers like Diodes Incorporated / Diodes Inc.), a 600V, 15A single-phase glass passivated bridge rectifier. It is designed to convert alternating current (AC) into direct current (DC). Featuring high forward surge current capability, low reverse leakage, and high dielectric strength, it includes a mounting hole for easy heat-sink attachment in high-power conversion stages. Key Specifications Type: Single-Phase Glass Passivated Bridge Rectifier Package Marking: GBJ15J Package: GBJ / 4DIP (4-pin in-line through-hole) Maximum Repetitive Peak Reverse Voltage ( $V_{RRM}$ ): 600V Maximum RMS Voltage ( $V_{RMS}$ ): 420V Maximum DC Blocking Voltage ( $V_{DC}$ ): 600V Maximum Average Forward Rectified Current ( $I_{F(AV)}$ ): 15A (with heat sink, $T_C = 100^\circ\text{C}$ ) / 3.2A (without heat sink, $T_A = 25^\circ\text{C}$ ) Peak Forward Surge Current ( $I_{FSM}$ ): 240A (8.3 ms single half sine-wave) Forward Voltage Drop ( $V_F$ ), max: $1.0\text{ V}$ per element at $I_F = 7.5\text{ A}$ Reverse Leakage Current ( $I_R$ ), max: $5.0\,\mu\text{A}$ at rated $V_{DC}$ ( $T_J = 25^\circ\text{C}$ ) Operating Junction Temperature Range: $-55^\circ\text{C}$ to $+150^\circ\text{C}$ Common Applications AC-to-DC primary rectification in high-power Switch-Mode Power Supplies (SMPS) Uninterruptible Power Supplies (UPS) and battery chargers Power supplies for home appliances (air conditioners, washing machines, audio amplifiers) Industrial power control circuits and AC motor drives Package Includes 1 x GBJ15J 600V 15A Single-Phase Bridge Rectifier (GBJ Package)
