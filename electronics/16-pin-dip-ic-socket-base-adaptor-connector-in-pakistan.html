Product details

16 Pin IC Socket base adaptor is a 16 pin IC holder, which can be solder directly onto the PCB. The IC can be remove from this socket when require. The IC is place on the socket at the time of use. This base acts as a removable IC holder. The socket is use when the IC is temperature sensitive and the heat from the soldering iron can damage the IC. This socket is used when working with a microcontroller IC and can be removed for programming. Features of 16 Pin IC Socket base adaptor : 16 pins. JDEC compliant. Molded notch for proper orientation. Easy to insert and remove ICs. Package Includes: 1 x 16 Pin DIP IC Base Adaptor
