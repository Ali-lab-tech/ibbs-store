Product details

Versatile Digital Display Module for Load Cell Applications This intelligent load cell display module features a bright 4-digit LED display and works with any resistor bridge load cell, with or without the HX711 instrumentation amplifier. Perfect for DIY scales, force measurement projects, and maker applications. Key Features: Universal Compatibility: Works with any resistor bridge load cell (covers virtually all load cells on the market) Flexible Power Options: Micro USB, 0.1" header pins, or barrel plug connector Clear 4-Digit LED Display: Easy-to-read seven-segment display for weight/force readings TTL Serial Data Output: Access raw data via serial communication Bidirectional Measurement: Displays accurately in both positive and negative directions No Weight Limit: Capacity depends entirely on your chosen load cell Easy Calibration: Simple button-based setup and calibration process Control Buttons: Enter: Access settings menu (press and hold) Left: Tare function / Navigate parameters (press and hold) Up: Calibrate weight / Adjust values (press and hold) Down: Calibrate zero / Adjust values (press and hold) Setup Instructions: Connect your load cell, then power the board Press and hold "Enter" to access parameter settings Use "Up"/"Down" to change values, "Enter" to save, "Left" to navigate Remove force from load cell, press and hold "Down" to calibrate zero point Add known calibration weight, press and hold "Up" to set calibration value Press "Enter" to save, then press and hold "Left" to tare Technical Specifications: Model: AD17-2021-11-01 Display: 4-digit seven-segment LED Compatible with HX711 load cell amplifier Data interface: TTL serial output Power input: Micro USB / 0.1" header / barrel jack What's NOT Included: No unit conversions (displays raw values in your chosen unit) No USB data communication (serial TTL only) Load cell sold separately Note: Full recalibration required when swapping load cells with different capacity or mV/V ratings. Taring is sufficient when using identical replacement load cells. Ideal for building custom scales, force gauges, tension meters, and other precision measurement projects.
