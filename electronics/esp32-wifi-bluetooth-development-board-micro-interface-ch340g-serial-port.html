Product details

The HK-ESP32-CAM-MB module is a small camera module with a size of 39.8*27*. This module can work independently as the smallest system. A new WiFi+Bluetooth dual-mode development board based on ESP32 design, using PCB on-board antenna, with 2 high-performance 32-bit LX6CPU, using 7-level pipeline architecture, main frequency adjustment range 80MHz to 240Mhz. Ultra-low power consumption, deep sleep current is as low as 6mA. It is an ultra-small 802.11b/g/n Wi-Fi + BT/BLE SoC moduleHK-ESP32-CAM-MB adopts Micro USB interface, convenient and reliable connection method, convenient to apply to various IoT hardware terminal occasions. Features: Using low-power dual-core 32-bit CPU, which can be used as an application processor. The main frequency is up to 240MHz, and the computing power is up to 600 DMIPS Built-in 520 KB SRAM, external 8MB PSRAM Support UART/SPI/I2C/PWM/ADC/DAC and other interfaces Support OV2640 and OV7670 cameras, built-in flash Support picture WiFI upload Support TF card Support multiple sleep modes.
