Product details

The Raspberry Pi 3 Model B is the third generation Raspberry Pi. Built on the latest Broadcom 2837 ARMv8 64bit processor the new generation Raspberry Pi 3 Model B is faster and more powerful than its predecessors. This powerful credit-card sized single board computer can be used for many applications and supersedes the original Raspberry Pi Model B+ and Raspberry Pi 2 Model B. Whilst maintaining the popular board format the Raspberry Pi 3 Model B brings you a more powerful processor, 10x faster than the first generation Raspberry Pi. It has improved power management to support more powerful external USB devices and further to customer feedback based development the new Raspberry Pi 3 now comes with built-in wireless LAN and Bluetooth connectivity making it the ideal solution for powerful connected designs.
