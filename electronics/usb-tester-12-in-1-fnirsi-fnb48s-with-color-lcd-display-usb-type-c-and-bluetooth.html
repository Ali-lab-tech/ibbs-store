Description FR FNB48S BT USB Tester The FR FNB48S BT USB Tester is a feature-rich USB voltage and current meter with built-in Bluetooth connectivity, making it perfect for engineers, developers, and DIY testers who want remote monitoring and real-time logging. Compatible with both USB-A and USB-C ports, this tester provides accurate data for voltage, current, power, capacity, resistance, and more. Its PD and QC trigger functionality allows for precise control and testing of fast charging modes. The built-in Bluetooth allows connection to mobile apps for graphical logging and remote display. Ideal use of FR FNB48S BT USB Tester is for power banks, fast chargers, PD adapters, mobile diagnostics, and embedded USB projects.
