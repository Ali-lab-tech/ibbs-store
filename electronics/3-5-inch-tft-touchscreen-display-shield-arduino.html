Product details

Build bright, interactive Arduino projects with this 3.5-inch TFT touchscreen display shield . It fits directly onto compatible Arduino boards and combines a vivid 480 × 320 colour display with a resistive touch panel. Key Features 3.5-inch colour TFT LCD with resistive touchscreen 480 × 320 pixel resolution ILI9486 display driver Compatible with Arduino UNO, Mega 2560 and Leonardo Standard Arduino shield interface — no separate interface board required Built-in microSD card socket and SPI Flash circuit Includes stylus pen Specifications Display size: 3.5 inch Resolution: 480 × 320 pixels Touch type: Resistive touch Operating voltage: 5V DC Data interface: 8-bit parallel Driver IC: ILI9486 Applications Ideal for Arduino dashboards, instruments, data loggers, menu-based controls, GPS projects, DIY game consoles and other embedded projects. Package includes: 1 × 3.5-inch TFT Touchscreen Display Shield with stylus.
