Product details

Description Marked "TMBRF20100CT" on the package, this is a TMBRF20100CT (Trench MOS Barrier Schottky Rectifier) Dual Diode in a common cathode configuration. Utilizing advanced trench MOS technology, it offers ultra-low forward voltage drop, reduced switching losses, and enhanced thermal stability compared to conventional Schottky rectifiers. Housed in a fully isolated ITO-220AB (TO-220F) plastic package, it provides internal electrical isolation, enabling direct mounting onto heat sinks without requiring an insulating washer. Key Specifications Type: Dual Trench MOS Barrier Schottky Rectifier (Common Cathode) Package Marking: TMBRF20100CT / 925 Package: ITO-220AB / TO-220F (Isolated 3-pin through-hole) Peak Repetitive Reverse Voltage ( $V_{RRM}$ ): 100V Average Rectified Forward Current ( $I_{F(AV)}$ ): 20A Total (10A per leg) Peak Forward Surge Current ( $I_{FSM}$ ): 150A (8.3 ms single half sine-wave) Forward Voltage Drop ( $V_F$ ), max: $0.75\text{ V}$ at $I_F = 10\text{ A}$ ( $T_J = 25^\circ\text{C}$ ) Reverse Leakage Current ( $I_R$ ), max: $100\,\mu\text{A}$ at rated $V_{RRM}$ ( $T_J = 25^\circ\text{C}$ ) Operating Junction Temperature Range: $-55^\circ\text{C}$ to $+150^\circ\text{C}$ Common Applications High-frequency Switch-Mode Power Supplies (SMPS) Secondary-side output rectification in power adapters and server power supplies DC-DC converters and battery chargers Reverse polarity protection and freewheeling diode applications Package Includes 1 x TMBRF20100CT 100V 20A Dual Trench Schottky Diode (ITO-220AB)
