Product details

SI2300DS 30V 3.6A N-Channel Mosfet – SOT-23 Package This N−Channel logic level enhancement mode field effect transistor is produced using on semi’s proprietary, high cell density, DMOS technology. This very high-density process is specially tailored to minimize on−state resistance. This device has been designed especially for low-voltage applications to replace digital transistors. Since bias resistors are not required, this one N−channel FET can replace several different digital transistors, with different bias resistor values.
