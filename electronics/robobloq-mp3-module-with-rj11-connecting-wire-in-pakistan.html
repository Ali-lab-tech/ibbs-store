Product details

The MP3 module is a sound module that can be used to play various animal sound effects mechanical sound effects and songs. This module can be used in combination with the robot's actions to bring more life to the Robobloq robot kit. The module supports two modes: APP mode- Users can use APP to play various sound effects songs and recording files in real-time. TF Mode- Plays songs from the Micro SD card Features : Onboard blue LED indicator for Bluetooth connection feedback High-definition speakers playing various audio effects in real-time The app supports dynamic audio effects and recordings Support Arduino IDE programming and provides runtime to simplify programming Supports Robobloq graphical programming for all ages The on-board gold-immersed M4 mounting holes make it easy to install The RJ11 jack makes it easy to connect to the robot kit Specifications: Operating voltage: DC 5V Working temperature: -20°C-70°C Working current: 300mA Working mode: APP Bluetooth mode; TF card mode Size: 58 x 43 x 28 mm (length x width x height) Package Includes: 1 x MP3 Module 1 x RJ11 Wire
