Wide use in the house, shopping center, electric motor, cars, motorcycle anti-theft alarm system or other control systems. Specified as preferred components in the remote control garage, roller blind, door locks, remote sensing, telemetry, industrial control and wireless security alarm industry. Output Operation: Jog / Unlocked, press a button, works / loosens and release your finger on the same button is stop / off. (A channel change needs a key on the remote control) Auto lock: Press a button for a time works / up and press the same button is stop / off. (A channel change needs a button on the remote control) Interlock / locked: Press one button works / up and another button press / off stop. (A channel change requires 2 buttons on the remote control) Learning and procedures for removing: Learning method: Press the learning code for 3 seconds. The indicator will then flash, and then loosen the finger, press any key to transmit the remote signal, the indicator will flash 3 times and then usually that means you will learn it successfully. Remove / clean method: The learn button will press approximately 8 seconds, the display will be from being away all the time, it means to keep the information you have successfully removed Wiring diagram: +V : 12V + input ; – V: 12V – input ; NO: Output , normal open; COM: Output , common ; NC: Output , normal close.
