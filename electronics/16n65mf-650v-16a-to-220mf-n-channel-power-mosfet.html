Product details

Description Marked "16N65MF" on the package with a "PY" logo, this is a 16N65MF-family N-channel power MOSFET, a common generic part number produced by multiple Asian semiconductor manufacturers. It's housed in the isolated TO-220MF (Modified F-pack) package, a two-pin-plus-tab variant commonly used to allow direct heatsink mounting without a separate insulating pad. The 16N65MF is built for offline switch-mode power supply applications, offering the standard feature set common to this class of 650V super-junction/planar MOSFET: low gate charge for faster switching, low input capacitance (Ciss) to reduce driving losses, 100% avalanche testing for ruggedness, and improved dv/dt capability for robustness against fast voltage transients. Key Specifications Type: N-Channel Enhancement Mode Power MOSFET Package Marking: 16N65MF Package: TO-220MF, isolated, 3-pin (Gate, Drain, Source) Drain-Source Voltage (VDSS): 650V Gate-Source Voltage (VGSS): 30V Drain Current (ID): 16A RDS(ON), max: 0.45Ω @ VGS=10V, ID=8A Features: Low gate charge, low Ciss, fast switching, improved dv/dt capability, 100% avalanche tested Common Applications Switch-mode power supplies (SMPS) Offline flyback and forward converters General-purpose 650V-class power switching designs Package Includes 1 x 16N65MF N-Channel Power MOSFET (TO-220MF)
