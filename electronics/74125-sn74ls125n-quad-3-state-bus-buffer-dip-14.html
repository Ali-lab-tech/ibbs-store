Description The SN74LS125N is a Quadruple Bus Buffer with 3-State Outputs, manufactured by Texas Instruments and housed in a standard 14-pin DIP through-hole package. This device contains four independent non-inverting buffer gates, each with an individual active-LOW enable input controlling its 3-state output. When enabled, the outputs exhibit the low-impedance characteristics of a standard TTL/LS output, with additional drive capability that allows the buffers to drive bus lines directly, without needing external pull-up resistors. When disabled, each output goes into a high-impedance ("3-state") condition, effectively disconnecting it from the bus — a key feature for designs where multiple devices need to share a common data or address bus without conflict. This makes the SN74LS125N a common choice for bus interfacing, tri-state data bus control, memory and I/O bus isolation, and any digital system where signal lines must be selectively enabled or floated. Key Specifications Function: Quad non-inverting buffer with 3-state outputs (negative/active-LOW enable) Logic Family: TTL, Low Power Schottky (LS) Package: 14-pin PDIP (through-hole) Output Type: 3-state, high drive capability for bus lines Manufacturer: Texas Instruments Common Applications Tri-state bus buffering and isolation in microprocessor systems Memory and I/O bus interfacing Signal line enabling/disabling in shared bus architectures General digital logic buffering in TTL-based designs Package Includes 1 x SN74LS125N IC (14-pin DIP)
