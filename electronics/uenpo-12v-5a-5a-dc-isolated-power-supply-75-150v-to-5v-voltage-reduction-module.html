Product details

UENPO Isolated DC-DC Voltage Reduction Module This UENPO isolated DC-DC power module converts a high-voltage DC input to a regulated 5V DC output. It is designed for 75V to 150V DC input systems, including common 96V, 108V and 120V DC applications. The isolated design helps separate the input and output sides for suitable low-voltage electronic loads. Key Features Wide input voltage range: 75V to 150V DC Regulated 5V DC output Maximum output current: 5A Maximum output power: up to 25W Isolated DC-DC power conversion design Compact enclosed module with connection wires Specifications Brand UENPO Converter type Isolated DC-DC step-down converter Input voltage 75V to 150V DC Compatible nominal systems 96V, 108V and 120V DC Output voltage 5V DC Maximum output current 5A Maximum output power 25W SKU B708 Suitable Applications High-voltage DC battery and power systems Industrial control and monitoring equipment 96V, 108V and 120V DC systems needing a 5V supply Electronics projects requiring an isolated low-voltage DC output Important Notes Use only with DC input within the stated 75V to 150V range. Confirm the wiring and polarity from the module label before connecting power. Do not exceed the 5A maximum output current or 25W load. High voltage can be dangerous. Installation should be performed by a qualified person. Package Includes 1 × UENPO Isolated DC-DC Voltage Reduction Module
