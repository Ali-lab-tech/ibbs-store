CN3302 Type-C 2S Lithium Battery Charger Module – 8.4V Step-Up Boost Charging Board (3–6V USB-C Input) Charge any 2S (7.4V) Li-ion or Li-Po battery pack from a standard 5V USB Type-C source with this compact step-up (boost) charging board, built around the Consonance CN3302 PFM step-up charge controller. It boosts a 3–6V USB-C input up to a regulated 8.4V using a true constant-current + Quasi-CV charge profile, with an external N+P power MOSFET, SS34 Schottky, and 10µH inductor for reliable energy transfer. Ideal for DIY power banks, 18650/21700 packs, robotics, solar projects, and portable electronics. ⚠️ 5V USB-C input ONLY. Do NOT apply 12V or anything above 6V — it will destroy the board. For a 12V source you need a buck (step-down) 2S charger, not this boost module. Key Features Consonance CN3302 controller — PFM step-up charge management driving an external N+P MOSFET Wide USB-C input — works from 2.75V to 6.5V (board rated 3–6V); on-chip UVLO shuts down below ~2.65V True CC + Quasi-CV charging — constant current until 8.4V, then reduced-current Quasi-CV, then automatic termination Selectable charge current — set by the on-board RCS sense resistors (1A / 2A / 4A solder-jumper versions) Solar / weak-adapter friendly — input-power-adaptive function automatically lowers charge current to match a weaker source Automatic recharge — resumes charging if the pack drops below the recharge threshold while still plugged in Dual status LEDs — CR (charging) and OK (full / constant-voltage) How It Charges On power-up the CN3302 begins constant-current charging. As the pack approaches 8.4V it enters Quasi-CV mode (charge current is reduced) to compensate for voltage drop across the cells' internal resistance, then terminates cleanly. If the battery later falls below the recharge threshold, charging restarts automatically.
