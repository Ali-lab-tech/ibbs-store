Product details

MSP2807 Full Color TFT Touch Display Module [2.8 inch] [320x240 Pixel] is a 2.8 inch, 320x240 Pixel, TFT touch panel display compatible with the punctual atom that is based on ILI9341 a-Si TFT LCD single chip driver. The ILI9341 chip can support 8-color display mode with standby mode for accurate drive through the software, so it is a good solution for driving small and medium-size LCD, suitable for handheld and portable applications such as smartphones, smartwatches, MP3 players, MP4 players, etc. This LCD module is a 16bit RGB 65K full-color TFT LCD with a touch screen that is equipped with LED PWM adjustable backlight. This LCD module is portrait mode, if you would like to use landscape mode, you need to use some tricks or use technical support. The TFT Display communicates with the microcontrollers and Arduino boards trough 4pins SPI protocol. Also, this module is equipped with an SD memory slot. and can be supplied with TTL (3.3V DC) up to 5V C. So before connecting it directly to the 5v logic level of the Arduino, ensure that has a voltage regulator, because the display may be destroyed if the version of the display you have does not have the regulator. If the display does not have a voltage regulator, you can use any logic level converter between the display and the Arduino Features: Screen size: 2.8 inch Display color: RGB 65K color Resolution: 320 x 240 (Pixel) Type: TFT LCD Driver IC: ILI9341 Interface: 4-wire SPI interface VCC supply voltage: 3.3V~5V Logic IO port voltage: 3.3V (TTL) Power consumption: About 90mA Operating temperature: -20°C ~ 70°C storage temperature: -40°C ~ 70°C Active area: 43.2mm x 57.6mm PCB Size: 50mm x 86mm Package Include: 1 x 2.8 Inch SPI Touch Lcd Module
