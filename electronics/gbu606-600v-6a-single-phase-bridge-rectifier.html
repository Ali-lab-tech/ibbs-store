Product details

Description This is a GBU606 , a 600V, 6A single-phase glass passivated bridge rectifier. It is designed to convert alternating current (AC) input into direct current (DC) output. Featuring high surge current capability, low forward voltage drop, and high reliability, it is designed for direct printed circuit board (PCB) mounting with a center hole for easy heat-sink attachment. Key Specifications Type: Single-Phase Glass Passivated Bridge Rectifier Manufacturer: Kingtronics (Kt) Package Marking: GBU 606 Package: GBU (4-pin in-line through-hole) Maximum Repetitive Peak Reverse Voltage ( $V_{RRM}$ ): 600V Maximum RMS Voltage ( $V_{RMS}$ ): 420V Maximum DC Blocking Voltage ( $V_{DC}$ ): 600V Maximum Average Forward Rectified Current ( $I_{F(AV)}$ ): 6A (with heat sink, $T_C = 100^\circ\text{C}$ ) Peak Forward Surge Current ( $I_{FSM}$ ): 175A (8.3 ms single half sine-wave) Forward Voltage Drop ( $V_F$ ), max: $1.0\text{ V}$ per element at $I_F = 3.0\text{ A}$ Reverse Leakage Current ( $I_R$ ), max: $5.0\,\mu\text{A}$ at rated $V_{DC}$ ( $T_J = 25^\circ\text{C}$ ) Operating Junction Temperature Range: $-55^\circ\text{C}$ to $+150^\circ\text{C}$ Common Applications AC-to-DC mains rectification in Switch-Mode Power Supplies (SMPS) Battery chargers and power adapters Power supplies for home appliances (TVs, audio systems, washing machines) General-purpose AC-DC full-wave rectification circuits Package Includes 1 x GBU606 600V 6A Single-Phase Bridge Rectifier (GBU)
