Product details

The TTGO T-Call is an ESP32 development board that combines a SIM800L GSM module and ESP32 Module. Besides Wi-Fi and Bluetooth, you can communicate with this ESP32 board using SMS or phone calls. Additionally, you can connect the ESP32 to the internet using your SIM card data plan. This is great for IoT projects that don’t have access to a nearby router via Wi-Fi.
