18 Pin IC Socket base adaptor is an 18 pin IC holder, which can be soldered directly onto the PCB. The IC can be remove from this socket when required. The IC is placed on the socket at the time of use. This base acts as a removable IC holder. The socket is use when the IC is temperature sensitive and the heat from the soldering iron can damage the IC. This socket is use when working with a microcontroller IC and can be remove for programming. Features of 18 Pin IC Socket base adaptor : 18 pins. JDEC compliant. Molded notch for proper orientation.
