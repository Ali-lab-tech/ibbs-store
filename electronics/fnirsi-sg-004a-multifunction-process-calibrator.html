Product details

The FNIRSI SG-004A is a multifunction process calibrator for instrument technicians. It sources and reads current, voltage, frequency/PWM, millivolt and thermocouple signals, and simulates resistance and RTD sensors such as Pt100 and Cu50. Current and voltage accuracy is ±(0.02% + 0.003) with 0.001 resolution, and it covers ten thermocouple types (S, B, E, K, R, J, T, N and two tungsten-rhenium types). Programming mode, history records, real-time curves and Modbus make it useful for both bench calibration and field loop checks. Key Features 🎯 ±(0.02% + 0.003) accuracy on mA and V with 0.001 resolution 🌡️ Thermocouple simulation and measurement for S, B, E, K, R, J, T, N and WRe types 🔥 RTD simulation Pt100 (-200 – 650°C) and Cu50 🔌 Active, passive and 24V loop current 0 – 24mA 📈 Program mode, history and real-time curve 🖧 Modbus slave and USB firmware upgrade Technical Specifications Current output 0 – 24mA, ±(0.02% + 0.003) Voltage output 0 – 24V, ±(0.02% + 0.003) 24V loop 0 – 24mA, ±(0.1% + 0.005) Frequency / PWM 0 – 9999Hz, ±2% Millivolt -10 – 100mV, ±(0.03% + 0.003) Thermocouple K 0 – 1320°C, ±(0.2% + 1) Resistance 0 – 390Ω output; 0 – 400Ω input Pt100 -200 – 650°C, ±(0.5% + 1) Display 2.4" TFT colour Battery 3000mAh, 24 h standby Charging USB-C 5 – 12V, 10W max Size 82 × 27 × 112 mm What's in the Box 1 × FNIRSI SG-004A calibrator Test leads and USB-C cable as supplied by FNIRSI
