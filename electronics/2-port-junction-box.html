Product Description: Use one network cable run for two devices with this compact RJ45 splitter. It has one female port on one side and two female ports on the other, so you can connect two Ethernet cables where only one cable comes from the wall or router. It's a handy fix when running a second cable isn't practical. Key Features: 1 to 2 RJ45 female-to-female splitter design Works with standard Cat5, Cat5e and Cat6 Ethernet cables Compact plastic body, easy to carry and install Gold-plated contacts Plug and play, no software or power needed Ideal For: Sharing one cable between a PC and a smart TV, console or set-top box Homes, offices and shops where cable runs are limited Usage: Splitters like this work in pairs: you need one at each end of the cable. Each device also gets up to about 100 Mbps, not gigabit speed, and both devices can't use the cable at full speed at the same time. It is not a network switch.
