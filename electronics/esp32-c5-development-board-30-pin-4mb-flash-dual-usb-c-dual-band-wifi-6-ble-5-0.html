Product details

The ESP32-C5 Development Board is built around Espressif's newest ESP32-C5HF4 module — the first ESP32 chip with true dual-band Wi-Fi (2.4GHz & 5GHz, 802.11b/g/n/ax / Wi-Fi 6) . It also adds Zigbee 3.0 and Thread 1.3 alongside Bluetooth LE 5.0, making it a genuine multiprotocol board for serious IoT and smart-home projects, not just another ESP32 clone. Key Features: ESP32-C5HF4 module — dual-band 2.4GHz/5GHz Wi-Fi 6, RISC-V core Multiprotocol radio — BLE 5.0, Zigbee 3.0, and Thread 1.3 on the same chip 4MB Flash storage, 30-pin header layout Dual USB-C ports — one USB_JTAG (native debugging), one USB_TTL via CH340X (UART/programming) Onboard RGB LED (WS2812, GPIO27) for status indication RST and BOOT buttons , AMS1117 3.3V regulator Compact form factor: 25.5mm × 57mm Why It's Different From a C3/S3 Board: Your existing ESP32-C3 and ESP32-S3 boards are 2.4GHz-only. The ESP32-C5 is Espressif's first chip to bring 5GHz Wi-Fi to the ESP32 family, plus Zigbee and Thread support for mesh/smart-home projects — useful wherever 2.4GHz is congested or a project specifically needs Zigbee/Thread connectivity. Compatible With: Arduino IDE, ESP-IDF, MicroPython (check current framework support for the C5 target before starting a project, since it is a newer chip). Package Included: 1 x ESP32-C5 Development Board (30-pin, 4MB Flash)
