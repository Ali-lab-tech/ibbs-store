LR7843 MOSFET Control Relay Module - Solid State Relay (SSR) Replacement The LR7843 is a high-performance MOSFET-based control relay module designed as a solid-state relay (SSR) replacement for traditional mechanical relays. Featuring the LR7843 transistor and IRF843 MOSFET, this module provides reliable, fast switching for DC loads with PWM control capability, making it ideal for Arduino projects, motor control, LED dimming, and automation applications.
