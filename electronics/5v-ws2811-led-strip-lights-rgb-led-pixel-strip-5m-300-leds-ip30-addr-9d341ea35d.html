Application: 12V WS2811 Dream Colour Strips 300 LEDs 5M Can be used to make LED screens, LED walls, billboards, entertainment decorations to enhance the atmosphere, widely used in hotels, KTV, bars, outdoor advertising signs, Christmas or wedding decorations, etc. The WS2811 LED strip has a display with 256 brightness levels and a 24-bit colour display. Each pixel can have its own colour and brightness. Dream Color Programmable LED colour strip, Addressable groups of 3 LEDs, one WS2811 IC controls three LEDs, Works great with Arduino, Ready-to-Go library, FastLED library and Raspberry Pi etc. It is easy to programme. Supports SP105E, SP611E, SP511E, SP604E, SP511E, SP608E, K-1000C etc APP Controller, SP106E, SP107E etc Music Controller, SP501E etc; Smart WiFi Alexa Controller. LED light strip with 3-pin JST SM connectors and separate power/ground cables at both ends. Each 3 LEDs can be cut off without damaging the remaining strip. You can shorten, lengthen or bend it as required. Supports DC12V only. Never use DC24V. Package: Include 5m led strip, note: power supply and controller not included, If you have any questions, please feel free to contact us. package includes 1 x 12v ws2811 led strip 5 meter 300 led in 5 meter 1 x 12v 3amp power adapter 1 x remote
