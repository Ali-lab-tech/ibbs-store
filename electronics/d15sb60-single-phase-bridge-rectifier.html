Description Marking on Device: D15SB60, SIYU, JI36 Device Type: Single-Phase, Full-Wave Bridge Rectifier Package: SIP-4P (Single In-Line Package, 4 Pins, with center mounting hole) Pin Configuration (left to right, as marked on body): Pin Symbol Function 1 + DC Output (Positive) 2 ~ AC Input 3 ~ AC Input 4 − DC Output (Negative) What This Component Does This device converts an AC (alternating current) input into a pulsating DC (direct current) output. It packs four diodes internally in a bridge configuration, enabling full-wave rectification from a single component — both halves of the incoming AC waveform are converted into usable DC. It sits at the front end of a power supply, immediately after the transformer or AC input, and before the smoothing/filter capacitor stage. Without one, safe continuous current drops significantly — if a unit is failing under moderate load, check heatsink contact first. 600V VRRM is a hard limit: Reverse voltage transients above this (common with inductive loads such as motors, solenoids, or relay coils) can cause permanent damage. A snubber network or MOV across the AC input helps protect against this in real-world circuits. Inrush current at power-up is expected: A brief surge while charging input filter capacitors is normal and within the surge current rating, provided it's momentary and not sustained. AC input pins are non-polarized; DC output pins are not: The two "~" terminals can be wired in either orientation, but "+" and "−" DC outputs must be connected correctly to protect downstream components.
