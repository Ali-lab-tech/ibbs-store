Product details

The ESP 01 or ESP8266 WiFi Module is a self-contained SOC. ESP8266 serial module has integrated TCP/IP protocol stack that can give any microcontroller access to your WiFi network. The esp8266 wifi module Arduino is capable of either hosting an application or offloading all Wi-Fi networking functions from another application processor. Each ESP8266 module comes pre-programmed with an AT command set firmware, meaning, you can simply hook this up to your Arduino device and get about as much WiFi-ability as a WiFi Shield offers (and that’s just out of the box)! The esp 01 connect to wifi module is an extremely cost-effective board with a huge, and ever-growing, community.
