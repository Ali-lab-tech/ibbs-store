Product details

Introducing the DC 12V 24V 4-20mA Signal Generator Module with Digital LED Display, a compact and user-friendly tool for signal sources, valve adjustment, and analog transmitter testing. This module is easy to connect with wire and provides good performance with its knob operation that instantly adjusts the response output without any delay. Here are some key features and applications of this Signal Generator Module: Features: Easy to use and connect with wire Knob operation for immediate response output adjustment Power supply voltage of DC 12V or 24V with total power <1W Output load impedance range of 0-350 ohms (DC12V) and 0-800 ohms (DC 24V) Display output on the 7 segment Applications: Signal sources Valve adjustment Output meter testing LED testing Analog transmitter testing Specifications: Power Supply: DC 12V or 24V Current: 4-20mA Total Power: <1W Output Load Impedance: 0-350 ohms (DC12V); 0-800 ohms (DC 24V) PCB Board Size: 50 * 50mm / 1.97 * 1.97in Product Weight: 38g / 1.37oz Package Includes: 1 x Signal Generator Module This Signal Generator Module is a versatile and reliable tool for signal sources and testing, with applications ranging from valve adjustment to LED testing. Its compact size, ease of use, and various features make it a must-have for anyone in need of a reliable signal source.
