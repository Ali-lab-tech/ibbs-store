Product details

The ESP32-P4 development board is a high-performance development board based on the ESP32-P4 and ESP32-C6, supporting Wi-Fi 6 and Bluetooth 5/BLE 5, and also supporting Xiaozhi AI DeepSeek. ESP32-P4-WIFI6-DEV-KIT Development Board High-performance development boards based on ESP32-P4 and ESP32-C6 Rich human-computer interaction interfaces Development Board Introduction This product is a high-performance RISC-V development board based on the ESP32-P4, featuring a dual-core processor and a single-core chip. It supports a rich set of human-machine interfaces, including MIPI-CSI (Integrated Image Signal Processor) and MIPI-DSI interfaces. It also supports common peripherals such as SPI, I2S, I2C, LED PWM, MCPWM, RMT, ADC, UART, and TWAI. Furthermore, it supports USB OTG 2.0 HS, Ethernet, and SDIO Host 3.0 for high-speed connectivity. The ESP32-P4 chip integrates a digital signature peripheral and a dedicated key management unit to ensure data and operational security. The ESP32-P4-WIFI6-DEV-KIT is designed for high-performance and high-security applications, fully meeting the higher demands of embedded applications for human-machine interface support, edge computing capabilities, and I/O connectivity. Key features: High-performance MCUs equipped with RISC-V 32-bit dual-core and single-core processors 128KB HP ROM, 16KB LP ROM, 768KB HP L2MEM, 32KB LP SRAM, 8KB TCM It boasts powerful image and audio processing capabilities, with interfaces including a JPEG codec, a pixel processing accelerator (PPA), an image signal processor (ISP), and an H.264 video encoder. The chip package contains 32MB of PSRAM, and the module integrates 16MB of Nor Flash. The board features common peripheral interfaces such as MIPI-CSI, MIPI-DSI, USB 2.0 OTG, Ethernet, SDIO 3.0 SD card slot, microphone, speaker terminals, and RTC battery terminals. The board has 2 × 20 pin headers, providing 28 additional programmable GPIO pins. Security mechanisms include Secure Boot, Flash encryption, a hardware encryption accelerator, and a hardware random number generator. It also supports hardware access protection, enabling Access Management (APM) and permission separation.
