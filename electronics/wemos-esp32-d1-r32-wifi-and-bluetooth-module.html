Product details

Development board with processor ESP32 with WiFi and Bluetooth (BLE) compatible Arduino Uno shields and it is faster than ESP8266 processors (i.e.: NodeMCU). It can be programmed with Arduino IDE and Facilino. Arduino IDE support: https://github.com/espressif/arduino-esp32 Characteristics: Power: 5-12VDC WiFi 802.11 b/g/n/e/i (802.11n upto 150 Mbps) Bluetooth v4.2 BR/EDR and BLE. Compatible with Arduino Uno shields. 6 analog input. 20 I/O digital (3.3V) (with PWM and interrupt). Communication UART, SPI, I2C. Size: 68×53 mm micro USB connection. 4Mbytes Flash Memory 520Kb Clock: 240Mhz (dedicated core to WiFi) Temperature: -40C > +85C Current: 250mA (max) Current at power save mode: 0.15mA Current normal mode: 20mA (no WiFi) Package Includes: 1x wemos esp32 D1
