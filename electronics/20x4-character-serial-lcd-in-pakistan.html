Product details

20x4 Green JHD204A Character LCD Display can be Interface with almost All Digital Microcontrollers. JHD204A Character LCD Display can be used with such as Arduino, 8051, PIC, AVR, ARM, MSP, COP8, STM, Raspberry Pi etc. About 20×4 Character LCD Display: 20×4 LCD is a basic 20 character by 4 line display Green/Yellow Backlight. Utilizes the extremely common HD44780 parallel interface chipset. Interface code is freely available. You will need 7 general I/O pins (If used in 4-bit Mode) to interface to this LCD screen. Includes LED Backlight.
