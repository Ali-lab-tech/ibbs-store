This Arduino Due microcontroller is based on the board of Atmel SAM3X8E ARM CortexM3 CPU. This Arduino due board is based on 32 bit ARM core microcontroller. Atmel SAM3X8E Arduino board contains 54 digital input/ output pins, 12 analog inputs, 4 UARTs, an 84 Mhz clock, an USB OTG capable connection, 2 DAC and DAC stands for Digital to Analog Converter, 2 TWI, a power jack, an SPI header, a JTAG header, a reset button and an erase button. Arduino board contains everything needed to support the microcontroller. We just need to connect the micro USB of Arduino Due to the computer. And this cable is included in the product pack. We just need to power it with an AC to DC adapter or battery to get started. This Arduino Due is compatible with all Arduino shields . And that works at 3.3V. these are compliant with 1.0 Arduino pinout. we provide high 6 inches micro USB cable with high-quality connection Arduino Due. Features Of Arduino Due ARM Cortex M3 Board With USB Cable : A 32-bit core, that allows operations on 4 bytes wide data within a single CPU clock. CPU clock at 84Mhz 96KBytes of SRAM 512KBytes of flash memory for code A DMA controller, that can relieve the CPU from doing memory intensive tasks.
