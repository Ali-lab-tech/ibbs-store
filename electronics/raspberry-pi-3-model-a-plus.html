Product details

Raspberry Pi 3 Model A+ The Raspberry Pi 3 Model A+ combines a 1.4GHz 64-bit quad-core processor with dual-band wireless LAN and Bluetooth 4.2/BLE. Its compact board has the same mechanical footprint as the Raspberry Pi 1 Model A+, making it a practical choice for embedded projects and connected electronics. Key Features Broadcom BCM2837B0 Cortex-A53 64-bit quad-core processor running at 1.4GHz 512MB LPDDR2 SDRAM Dual-band 2.4GHz and 5GHz 802.11 b/g/n/ac wireless LAN Bluetooth 4.2 with Bluetooth Low Energy (BLE) Extended 40-pin GPIO header for connecting project hardware Display, Camera and Audio 1 × full-size HDMI port MIPI DSI display port MIPI CSI camera port 4-pole stereo output and composite video port Multimedia Support H.264 and MPEG-4 decoding at 1080p30 H.264 encoding at 1080p30 OpenGL ES 1.1 and 2.0 graphics Storage and Power MicroSD card support for the operating system and data storage 5V/2.5A DC input via micro USB connector 5V DC input via GPIO header Operating temperature: 0–50°C
