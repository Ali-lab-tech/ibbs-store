Description: Marking on Device: TS25P05G, SHS, S3L3H Device Type: Single-Phase, Full-Wave Bridge Rectifier Package: TS-6P / SIP-4P (4-Pin, with center mounting hole) Pin Configuration (left to right, as marked on body): Pin Symbol Function 1 + DC Output (Positive) 2 ~ AC Input 3 ~ AC Input 4 − DC Output (Negative) What This Component Does This device converts an AC (alternating current) input into a pulsating DC (direct current) output. It contains four internal diodes arranged in a bridge configuration, allowing a single component to perform full-wave rectification — converting both halves of the incoming AC waveform into usable DC. It's a standard building block used right after the transformer or AC input stage in a power supply, ahead of the smoothing capacitor. If a circuit is running hot or underperforming, verify heatsink contact and thermal paste application. Do not exceed 600V VRRM: Voltage transients above this rating (common with inductive loads like motors, solenoids, or relays) can cause permanent junction breakdown. Adding a snubber circuit or MOV across the AC input is good practice in such circuits. Inrush current is normal on power-up: A brief current surge when charging input capacitors is expected and falls within the 350A surge rating — this is not indicative of a fault as long as it's momentary. AC pins are non-polarized; DC pins are not: The two "~" pins can be wired either way, but the "+" and "−" DC output pins must be connected correctly to avoid damaging downstream circuitry.
