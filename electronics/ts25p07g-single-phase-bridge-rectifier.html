Product Description The TS25PF07G Power Semiconductor Module is a compact high-power electronic component designed for use in power switching, control, and conversion circuits. It features a rugged molded package with four external terminals and mounting holes for secure installation on a PCB, heatsink, or suitable mounting surface. Its robust construction makes it suitable for various power electronics, industrial control, switching, and electrical conversion applications . The component should be used according to the manufacturer's electrical specifications and terminal configuration Component Identification Marking on Device: TS25P07G, SHS, S1D4 Manufacturer: Taiwan Semiconductor Corporation (TSC) Device Type: Single-Phase, Full-Wave Bridge Rectifier Package: TS-6P / SIP-4P (4-Pin, Through Hole, with center mounting hole) Pin Configuration (left to right, as marked on body): Pin Symbol Function 1 + DC Output (Positive) 2 ~ AC Input 3 ~ AC Input 4 − DC Output (Negative) What This Component Does This device converts an AC (alternating current) input into a pulsating DC (direct current) output. It integrates four diodes internally in a bridge configuration, enabling full-wave rectification from a single component. The "07" in the part number designates this as the highest voltage variant in the TS25P0xG series (TS25P01G through TS25P07G span 50V up to 1000V), making it suited for higher-voltage AC input rectification stages compared to its lower-numbered siblings.
