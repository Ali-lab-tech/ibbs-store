Product details

Description The SN74LS95N is a 4-Bit Parallel-Access Shift Register manufactured by Texas Instruments, housed in a standard 14-pin DIP through-hole package. It supports both serial and parallel synchronous operating modes, with the serial shift-right and parallel-load functions activated by separate clock inputs that are selected via a mode control input. This flexibility makes the SN74LS95N a versatile building block for data storage, serial-to-parallel or parallel-to-serial conversion, and general shift-register applications in digital logic circuits. Beyond parallel load and serial shifting, the chip also supports a hold mode that maintains the current register state without altering the stored data, which is useful for pausing data movement mid-operation without losing the current values. Its dual clock/mode-select architecture makes it straightforward to integrate into counters, data buffering circuits, and communication interfacing where controlled bit-shifting is required. Key Specifications Function: 4-bit universal/parallel-access shift register Logic Family: TTL, Low Power Schottky (LS) Package: 14-pin PDIP (through-hole) Operating Modes: Serial shift-right, parallel load, hold Output Current: 0.4mA sourcing (HIGH) / 8mA sinking (LOW) Manufacturer: Texas Instruments Common Applications Serial-to-parallel and parallel-to-serial data conversion Data buffering and temporary storage in digital circuits Shift-register-based counters and timing circuits General TTL logic design and educational digital electronics projects Package Includes 1 x SN74LS95N IC (14-pin DIP)
