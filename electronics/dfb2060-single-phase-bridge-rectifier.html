Description Marking on Device: ON (onsemi logo), QH51, DFB2060 Manufacturer: onsemi (ON Semiconductor) Device Type: Single-Phase, Full-Wave Bridge Rectifier Package: TS-6P / 4-SIP (4-Pin, Through Hole, with center mounting hole) Pin Configuration (left to right, as marked on body): Pin Symbol Function 1 + DC Output (Positive) 2 ~ AC Input 3 ~ AC Input 4 − DC Output (Negative) What This Component Does This device converts an AC (alternating current) input into a pulsating DC (direct current) output. It integrates four diodes internally in a bridge configuration, allowing full-wave rectification from a single component — both halves of the incoming AC waveform are converted into usable DC. It's typically placed right after the transformer or AC input stage in a power supply, ahead of the smoothing/filter capacitor. Core Electrical Ratings Parameter Symbol Rating Max Peak Reverse Voltage VRRM 600V Max DC Reverse Voltage VR 600V Average Rectified Forward Current Io 20A Max Forward Voltage Drop VF 1.1V @ 20A Max Reverse Leakage Current IR 10µA @ 600V Non-Repetitive Peak Forward Surge Current IFSM 250A Operating Junction Temperature TJ −55°C to +150°C Package / Case — 4-SIP, TS-6P Mounting Type — Through Hole Important Usage Notes (for support/troubleshooting reference) Heatsinking is required to reach the full 20A rating: The center mounting hole is designed for direct heatsink attachment. Without adequate heatsinking, safe continuous current is significantly lower — check thermal contact first if a unit is running hot or underperforming. 600V VRRM is a hard limit: Reverse voltage spikes above this rating — common with inductive loads like motors, solenoids, or relay coils — can permanently damage the internal diode junctions. A snubber circuit or MOV across the AC input is recommended in such circuits. Inrush current at power-up is normal: A brief current surge while charging input filter capacitors is expected and falls within the 250A surge rating, provided it's momentary rather than sustained. AC pins are non-polarized; DC pins are not: The two "~" terminals can be wired in either orientation, but the "+" and "−" DC output pins must be connected correctly to protect downstream circuitry.
