Product details

The WiFi R3 ATmega328P + ESP8266 Development Board is a powerful and flexible solution for Arduino and IoT projects. It combines ATmega328P and ESP8266 WiFi MCU on a single board, allowing users to develop standalone Arduino projects or WiFi-enabled applications with ease. This board features a CH340G USB-TTL converter , enabling simple programming via a Micro-USB cable. A built-in DIP switch allows easy switching between ATmega328P, ESP8266, or both, providing maximum flexibility during development.
