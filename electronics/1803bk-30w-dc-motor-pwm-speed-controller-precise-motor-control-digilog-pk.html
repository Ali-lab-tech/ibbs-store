1803BK 30W DC Motor PWM Speed Controller The 1803BK 30W DC Motor PWM Speed Controller offers precise control of DC motor speeds. Supporting a voltage range of 1.8V to 12V and a continuous current of up to 2A , this controller ensures smooth and adjustable motor performance. Its built-in switch function allows easy power control, and it supports a speed range from 0% to 100% . Please note that this controller should only be used with DC power sources—connecting it directly to AC 220V will cause damage.
