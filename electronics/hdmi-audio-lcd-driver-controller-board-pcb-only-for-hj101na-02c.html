Product details

Powerful and compact driver board to revive your LCD panel. This listing is for the LCD Controller Board (PCB) only . It is designed to drive the HJ101NA-02C 10.1-inch IPS LCD panel (and compatible 1280x800 screens). Powered by the versatile Realtek RTD2660H chipset, this board is the core component needed to turn a raw LCD panel into a functional HDMI monitor. Note: This is a replacement or DIY component. Ribbon cables, keypad boards, and power adapters are sold separately. Key Features: Replacement Part: Ideal for replacing a damaged driver board in an existing setup. Broad Compatibility: Specifically programmed for 40-pin LVDS panels like the HJ101NA-02C. HDMI Input: Standard HDMI port for easy connection to PCs, Raspberry Pi, and media players. Integrated Audio: Features a 3.5mm audio jack and a 4-pin speaker header on-board. USB-C Power: Modern 5V DC input via USB Type-C , allowing power from standard phone chargers or power banks. Technical Specifications: Feature Specification Model PCB800812V1 Main Chipset Realtek RTD2660H Supported Resolution 1280 x 800 (Designed for HJ101NA-02C) Video Input HDMI Audio 3.5mm Out + 4-Pin Speaker Header Panel Connector 40-Pin LVDS / 50-Pin TTL Power Interface USB Type-C (5V) Board Size 87.3mm x 52.7mm Interface Layout: HDMI: Video Signal Input USB Type-C: 5V Power Input 3.5mm Jack: Audio Output White 4-Pin Socket: Speaker Output (Left/Right) White 40-Pin Socket: LVDS Panel Connection White Keypad Socket: For OSD Control Board Package Includes: 1x HDMI LCD Controller Board (PCB Only) Important Note: Accessories Not Included: This listing does not include the LVDS ribbon cable, OSD keypad board, or LCD panel. You will need to provide these separately to complete the assembly. Compatibility Check: Please ensure your LCD panel model is HJ101NA-02C or electrically equivalent before use to avoid damage.
