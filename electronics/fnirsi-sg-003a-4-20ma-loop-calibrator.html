Product details

The FNIRSI SG-003A is a handheld process signal generator for commissioning PLC analog inputs, transmitters, valve positioners and panel meters. It sources and measures 0 – 24mA (active, passive or 24V loop) and 0 – 24V with ±(0.1% + 0.005) precision. Outputs can ramp automatically, step through four presets, or follow a custom range, and a live trend graph shows how the loop responds. It talks Modbus over RS485, runs 8 – 10 hours at 20mA output, and charges over Type-C. Key Features 🔌 0 – 24mA active, passive and 24V loop with 0.01mA resolution ⚡ 0 – 24V voltage output and 0 – 30V voltage input 📶 Frequency / PWM output 0 – 9999Hz with adjustable duty cycle 📈 Auto ramp, presets and real-time curve 🖧 RS485 Modbus slave for PLC or PC configuration 🔋 3000mAh battery 26 h standby, Type-C charging Technical Specifications Active current output 0 – 24mA, ±(0.1% + 0.005), max load 750Ω Passive current output 0 – 24mA, external 0 – 30V supply Voltage output 0 – 24V, 0.01V resolution 24V loop 0 – 24mA Frequency / PWM output 0 – 9999Hz, ±2% Current input 0 – 24mA, ±(0.1% + 0.005) Voltage input 0 – 30V, ±(0.1% + 0.005) Communication RS485, Modbus slave Display 2.4" TFT colour, 240 × 320 Battery 3.7V 3000mAh, 4 – 6 h charge Size 82 × 27 × 112 mm Weight 165 g What's in the Box 1 × FNIRSI SG-003A loop calibrator Test leads and USB cable as supplied by FNIRSI
