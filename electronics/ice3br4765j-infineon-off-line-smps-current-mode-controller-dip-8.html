Product details

Product Description The ICE3BR4765J is an off-line SMPS current mode controller from Infineon's CoolSET®-F3R jitter series, integrating a 650V CoolMOS® power switch and Startup cell into a compact PG-DIP-8 package. It's designed for off-line battery adapters and low-cost, lower-power SMPS applications such as DVD/Blu-ray players and set-top boxes. Building on the earlier CoolSET®-F3 series, it adds built-in soft start time, a built-in blanking window, built-in frequency jitter, and soft gate driving, while retaining active burst mode and auto-restart protection for improved efficiency and reduced standby power. Key Specifications Parameter Value Package PG-DIP-8 Integrated MOSFET Voltage (VDS) 650V Switching Frequency (FOSC) 65kHz (internally fixed, with frequency jitter) RDS(on) 4.70Ω (typ. @ Tj=25°C) Input Voltage Range 85–265 VAC Output Power (max, with heatsink) 27W Output Power (max, without heatsink) 18W Manufacturer Infineon Technologies AG Key Features 650V avalanche-rugged CoolMOS® with built-in Startup Cell Active Burst Mode for lowest standby power Fast load jump response in Active Burst Mode Built-in frequency jitter mode to reduce EMI Built-in soft start and soft gate driving for smoother startup behavior Typical Applications Off-line battery chargers / adapters Low-power SMPS designs (DVD/Blu-ray players, set-top boxes) Auxiliary/standby power supplies Package Includes 1x ICE3BR4765J IC (PG-DIP-8 package)
