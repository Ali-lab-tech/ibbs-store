Product details

The Board Consist of Ethernet port with onboard 802.11 b/g/n 2.4GHz WiFi and Bluetooth, the popular open source BeagleBone Black computer now comes with built-in wireless networking capability. Leveraging a partnership with Octavo Systems and designed in CadSoft Eagle, BeagleBone Black Wireless is the easiest to use and modify credit-card sized IoT Linux computer available. SPECIFICATIONS: SoC – Texas Instruments Sitara AM3358 Cortex A8 @ 1 GHz with PowerVR SGX530 GPU System Memory – 512 MB DDR3L Storage – 4GB eMMC flash + micro SD slot USB – 1x mini USB client port for power & communication, 1x USB host port Connectivity – 802.11 b/g/n WiFi + Bluetooth 4.1 LE with 2x u.FL antenna connectors Video & Audio Output – micro HDMI up to 1280×1024 resolution. Expansion Connectors – 2x 46-pin headers Misc – LEDs for WiFi, Bluetooth, Power, and 4x user LEDs; Reset, boot, and power buttons Debugging – JTAG header, serial console Power – mini USB, DC Jack, or 5VDC via expansion header Dimensions – 86.4 x 53.4 mm SOFTWARE COMPATIBILITY: Debian with Cloud9 IDE on Node.js w/ BoneScript library Third party support for Android and Ubuntu Plus much more INTERFACE: USB client for power & communications USB host 802.11b/g/n and Bluetooth 4.1 plus BLE HDMI 2x 46 pin headers PACKAGE INCLUDES: 1 X BeagleBone Black Wireless ARM Cortex-A8 (1GHz) Development Board
