Product details

The Pro’sKit 8PK-605A is a set of 5 miniature needle files designed for precision filing and shaping tasks. These tools are particularly useful for fine work or within restricted areas where standard files cannot reach. Each file in the set features a PVC coated handle to provide a secure grip during operation. The set is suitable for hobbyists, electronics technicians, and model makers requiring detailed material removal. Quantity: 5 needle files Handle material: PVC coated Overall length: 170mm ± 3mm Cut length: 75mm
