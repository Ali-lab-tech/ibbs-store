Orange Pi 3 LTS Single Board Computer 2GB RAM AllWinner H6 8GB eMMC Development Board – Supports Android 9.0, Ubuntu, and Debian The Orange Pi 3 LTS is a high-performance single-board computer designed for developers, makers, and tech enthusiasts. Powered by the AllWinner H6 quad-core 64-bit Cortex-A53 processor , it delivers exceptional computing power for multimedia, IoT, and embedded projects. With 2GB LPDDR3 RAM and 8GB eMMC storage , it provides smooth operation and fast data access. The board supports multiple operating systems including Android 9.0, Ubuntu, and Debian , making it ideal for versatile development environments. The integrated Mali T720 GPU supports advanced graphics rendering, 4K video decoding, and OpenGL ES3.1 for a rich multimedia experience. It also features Gigabit Ethernet , WiFi , and Bluetooth 5.0 for seamless connectivity. Perfect for DIY smart devices, AI projects, and mini PC builds, the Orange Pi 3 LTS offers reliable performance with compact design and low power consumption. Key Features: Powerful CPU: AllWinner H6, Quad-Core 64-bit Cortex-A53 @ 1.8GHz GPU: Mali-T720 with OpenGL ES3.1, DirectX 11 support Memory: 2GB LPDDR3 RAM (shared with GPU) Storage: 8GB eMMC Flash + TF Card Slot Connectivity: Gigabit Ethernet, Wi-Fi (802.11 a/b/g/n/ac), Bluetooth 5.0 Video Output: HDMI 2.0a, CVBS output, supports 4K video playback Audio: HDMI and 3.5mm audio port USB Ports: 1 x USB 3.0, 2 x USB 2.0 Expansion Header: 26-pin GPIO (I2C, SPI, UART supported) Power Supply: 5V/3A via Type-C Supported OS: Android 9.0, Ubuntu, Debian Package Includes: 1 x Orange Pi 3 LTS Development Board Orange Pi 3 LTS open source board adopts Allwinner quad core 64 bit A53 high-performance processor.
