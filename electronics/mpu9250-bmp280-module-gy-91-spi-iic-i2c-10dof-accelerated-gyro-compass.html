Product details

GY-91 MPU6500 + BMP280 7DOF IMU & Barometric Pressure Sensor Module The GY-91 module combines an MPU6500 6-axis IMU with a BMP280 barometric pressure and temperature sensor . It is suitable for motion sensing, orientation detection, altitude-related projects, robotics and flight-control experiments. Important: This version of the module does not have a magnetometer . It cannot measure magnetic field or provide a compass heading. It should not be used where a 9-axis/10DOF compass sensor is required. Key Features MPU6500: 3-axis accelerometer and 3-axis gyroscope BMP280: barometric pressure and temperature sensing 7DOF sensor combination: 6-axis motion sensing plus barometric pressure I2C and SPI communication support Onboard voltage regulation for convenient module power input Compact board for Arduino, ESP32, STM32, Raspberry Pi and compatible controllers Specifications Module GY-91 IMU chip MPU6500 Pressure sensor BMP280 Accelerometer 3-axis; selectable ±2g, ±4g, ±8g, ±16g ranges Gyroscope 3-axis; selectable ±250, ±500, ±1000, ±2000 °/s ranges Pressure range 300 to 1100 hPa Interfaces I2C / SPI Module supply 3V to 5V via onboard regulator Magnetometer Not included Suitable Applications Arduino and microcontroller motion projects Robot balancing, tilt and gesture detection Flight-controller and stabilization experiments Altitude and weather-related sensing projects DIY data logging and educational electronics Package Includes 1 × GY-91 MPU6500 + BMP280 sensor module Important Usage Notes Use 3.3V logic levels for sensor communication unless your controller board provides verified level shifting. This is a bare sensor module; it is not a complete flight controller. For magnetic heading or compass functions, choose a module that explicitly includes a magnetometer.
