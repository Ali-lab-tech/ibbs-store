Product details

LED 7 Segment 2 Digit Common Anode Display is 25mmx17mmx10mm display led screen. LED 7 Segment 2 Digit Common Anode Display, is a form of the electronic display device for displaying decimal Numericals that is an alternative to the more complex dot matrix displays. Used widely in home appliances, instrument, car accessory, etc. It is commonly used in Arduino projects. Features of LED 7 Segment 2 Digit Common Anode Display: Adopt 25mmx17mmx10mm 2-digit common Anode Nixie tube Adopt low-level signal control for Nixie tube segment / bit-choice Connect VCC to the power supply, GND to ground, segment terminal a, b, c, d, e, f, d, up to single-chip I/O port.
