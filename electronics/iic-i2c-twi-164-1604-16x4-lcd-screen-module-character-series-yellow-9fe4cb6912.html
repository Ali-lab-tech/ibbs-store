Product details

This is another large blue screen LCD. As the Arduino driver's pin resources are limited, your project may not be able to use a normal LCD shield after being connected with a certain number of sensors or SD card. However, with this I2C interface LCD module, you can perform data visualization through only 2 cables. If you already have I2C devices in your project, this LCD module does not cost more resources.It's great for a project based on Arduino.
