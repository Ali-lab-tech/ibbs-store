Product details

Convert your M.2 NGFF (SATA Channel) SSD into a standard 2.5-inch SATA hard disk interface with this high-speed adapter card. This adapter allows you to use M.2 SSDs in standard laptops, desktop computers, or SATA enclosures, making it an excellent tool for data recovery, system upgrades, or repurposing older M.2 drives. Designed with a high-quality PCB and robust voltage regulation, it supports M.2 SSDs of various lengths (2230 to 2280) and ensures stable data transmission at speeds up to 6Gbps. It is purely a hardware pass-through adapter, meaning no drivers are required—just plug and play. Key Features: High-Speed Transfer: Supports SATA III revision 3.1 interface with data transfer rates up to 6Gbps. Wide Compatibility: Supports M.2 NGFF SATA-based SSDs with B-Key or B+M Key interfaces. Multiple Sizes Supported: Compatible with four different SSD lengths: 2230, 2242, 2260, and 2280 . Stable Power: Built-in high-efficiency voltage regulator converts standard SATA 5V power to the 3.3V required by M.2 SSDs. Plug & Play: No software drivers required; works with Windows, Mac, Linux, and Raspberry Pi. Bootable: Can be used as a primary boot drive (depending on motherboard BIOS support). ⚠️ Important Compatibility Note: Supported: Works ONLY with M.2 SATA Protocol SSDs (B-Key or B+M Key). NOT Supported: Does NOT work with NVMe or PCIe SSDs (M-Key). Please check your SSD label before purchasing. Specifications: Feature Detail Input Interface M.2 NGFF (SATA Protocol) Output Interface SATA III (7+15 Pin) Supported Keys B-Key, B+M Key Supported Sizes 22x30mm, 22x42mm, 22x60mm, 22x80mm Transfer Speed Up to 6Gbps (SATA III) Board Dimensions Approx. 100mm x 44mm Board Color Blue Weight ~50g Package Includes: 1 x M.2 NGFF to SATA 3.0 Adapter Card screws
