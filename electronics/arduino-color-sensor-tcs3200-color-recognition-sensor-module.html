Product details

Arduino Color Sensor TCS3200 Color Recognition Sensor Module uses a high-quality light sensor therefore allowing you to sense any color through a combination of Red, Green, and Blue. However the module provides all of the pins of the TCS3200 on convenient 0.1″ headers . As well as ideal for use with PCBs, breadboard or stripboard. Firstly Four white LEDs provide plenty of light for the color sensor and allow you to use the module in any ambient light. The module requires only a single supply voltage between 2.7V and 5.5V – making it compatible with nearly all common microcontrollers, including PICs, AVRs, ARM as well as Arduino and more! Features of Tcs3200 color sensor: Firstly the pinout is clearly labeled on the board secondly is as follows: Header one on the left side of the board: S0: Output frequency scaling selection input (along with S1) S1: Output frequency scaling selection input (along with S0) OE: Output Enable – if held low, so the output of the module is turned on GND: Ground – connect to 0V Header two on the right side of the board : S3: Photodiode type (along with S2) S2: Photodiode type (along with S3) OUT: Output – A square wave appears here therefore showing the intensity of the detected colour VCC: Power – connect to 2.7V-5.5V However The Photodiode type pins allow you to pick which color light you are currently detecting: High S2 S3 Photodiode type Low Low Only red light Low High Only blue light High Low No filter High green light By combining the reading of each of the three colours, as a result you can identify any visible colour!
