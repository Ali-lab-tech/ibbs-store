Product details

IIC/I2C/TWI 1602 Serial Backlight LCD Display Module YwRobot For Arduino, Arduino IIC/I2C interface LCD1602 with Blue or yellow/green LCD. Arduino IIC/I2C interface was developed to reduce the IO port usage on the Arduino board. Old 1602 screen requires 7 IO ports but this module uses only two needed control panel IO ports that can be used to add some sensors, SD card, and so on. Features Of PCF8574T IIC I2C 1602 Blue-Green Backlight LCD Display Module For Arduino: Power supply voltage: +5V Support I2C protocol I2C Address: It’s either 0x27 or 0x3F Received an email from a customer saying that his board works with 0x3F Pin Definition: GND、VCC、SDA、SCL Power supply voltage: +5V Backlit (Blue with White char color or Green with White char color Size : 82x35x18 mm Contrast Adjust: Potentiometer LED is 16-Character 2-Line, blue Screen and white Character (STN Negative Blue) Be I2C-Bus Interface that can connect 8 devices together in the same bus (setup different Addresses) Use IC No.PCF8574A to expand Port for connecting with LCD Use Power Supply 5V DC This is another great LCD display. With limited pin resources, your project will quickly run out of resources using normal LCDs. With this I2C interface LCD module, you only need 2 lines (I2C) to display the information. If you already have I2C devices in your project, this LCD module actually costs no more resources at all. Fantastic for Arduino or gadgeteer-based projects. Documents: Manual Schematic
