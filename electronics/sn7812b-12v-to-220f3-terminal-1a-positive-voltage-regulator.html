Description Marked "AUK SN7812B" on the package with AUK Corp's logo (with "D" and "E" markings visible next to the mounting holes, indicating "D" for Drain-style output pin and "E" possibly a package/lead reference), this is AUK Corp's (Kodenshi AUK Group) SN7812B, part of the industry-standard 78xx series of fixed positive linear voltage regulators. It's a 3-terminal 1A positive voltage regulator that outputs a fixed, regulated 12V DC from a higher unregulated DC input. Like all 78xx-family regulators, it requires no external components for basic operation — just input voltage and ground connections yield a stable, regulated 12V output. It includes built-in current limiting and thermal (over-temperature) shutdown protection, making it a robust, drop-in solution for powering downstream circuitry that needs a clean, fixed 12V rail. Key Specifications Type: 3-Terminal Fixed Positive Linear Voltage Regulator Manufacturer: AUK Corp (Kodenshi AUK Group) Package Marking: AUK / SN7812B Package: TO-220F, isolated, 3-pin (Input, Ground, Output), through-hole Output Voltage: 12V (fixed) Output Current: 1A (typical for this series; some variants rated up to 1.5A) Input Voltage Range: ~14.5V to 27–35V DC (typical for 78xx family) Protection: Built-in current limiting, thermal overload (over-temperature) shutdown Common Applications General-purpose fixed 12V power supplies Regulated rails for op-amp circuits, audio amplifiers, and sensor interfaces Post-regulation stage after AC-DC rectification in linear power supplies Arcade, industrial, and consumer electronics repair/replacement (drop-in compatible with LM7812, MC7812, UA7812, and similar 78xx-family parts) Package Includes 1 x AUK SN7812B 12V Voltage Regulator (TO-220F)
