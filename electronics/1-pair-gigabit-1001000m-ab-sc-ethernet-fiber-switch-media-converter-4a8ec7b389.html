The Gigabit SC Fiber Media Converter is a device used to convert a standard Ethernet (RJ45) signal into fiber optic signal and vice versa. It allows you to extend your network over long distances using fiber cable instead of copper cable. ⚡ Key Features Gigabit Speed: Supports 10/100/1000 Mbps Ethernet for fast data transfer Long Distance Transmission: Extends network up to 20KM over single-mode fiber RJ45 + SC Fiber Ports: RJ45 port for Ethernet cable SC port for fiber optic cable A/B Pair (Bi-Directional): Comes as 2 units (A & B) that work together using different wavelengths (1310nm / 1550nm) Plug & Play: No configuration required — easy to install and use Auto-Negotiation: Automatically detects speed and duplex mode 🔌 How It Works 👉 Connect Router/Switch → RJ45 port (Converter A) 👉 Connect Fiber cable → between A & B converters 👉 Connect Converter B → RJ45 → Device (PC/Camera/Switch) ✔ Converts electrical signals to optical signals for long-distance transmission 📦 What’s Included 1 × Converter (TX/A) 1 × Converter (RX/B) Power adapters 🧰 Applications CCTV camera systems Office or building networking Internet extension over long distances Industrial and outdoor networking ⚠️ Important Notes Requires single-mode fiber (SC connector) Must use both A & B units together Maximum 100m on RJ45 side , longer via fiber 💡 Simple Explanation 👉 It’s like a network extender : Instead of using short Ethernet cables, it lets you send internet up to 20KM using fiber optic cable .
