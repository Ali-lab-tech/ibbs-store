Product details

DS1302 Real Time Clock Module The DS1302 is a trickle-charge clock chip containing a real-time clock/calendar and 31 bytes of static RAM. It communicates with a microcontroller via a simple serial interface. Features 31 x 8 byte temporary data storage RAM Serial I/O port minimizes required pins Wide operating voltage range: 2.0V to 5.5V Low current consumption: less than 300nA at 2.0V Read/write clock or RAM data in single-byte or multi-byte transfer modes Available in 8-pin DIP or SOIC package Simple 3-wire interface TTL-compatible (Vcc = 5V) Optional industrial temperature range: -40°C to +85°C Dual power pins for main and backup power supply Specifications PCB size: 42mm x 24mm x 12mm (max) Color: Green Battery: CR2032 (3V, 260mAh, non-rechargeable) Crystal: 32.768KHz, 6pF matching capacitance, 2mm x 6mm size Operating voltage: 3.3V or 5V Operating temperature: 0°C to 70°C Wiring (Example for reference) **Important Note:** VCC and GND must not be reversed to avoid damaging the chip. VCC → +5V/3.3V GND → GND CLK → P02 (Microcontroller Pin) DAT → P01 (Microcontroller Pin) RST → P00 (Microcontroller Pin) **Note:** The specific microcontroller pin connections may vary. You might need to adjust these based on your program and microcontroller configuration. Package Includes 1 x DS1302 Real Time Clock Module with battery Note: Color Might Be Blue Or Green
