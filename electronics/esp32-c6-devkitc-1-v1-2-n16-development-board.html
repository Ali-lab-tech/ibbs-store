Product details

ESP32-C6-DevKitC-1 v1.2 N16 The ESP32-C6-DevKitC-1 is Espressif's official entry-level development board built around the ESP32-C6-WROOM-1 module, this N16 variant featuring 16MB of onboard SPI flash — double the standard 8MB version — for larger firmware images, OTA updates, and data logging applications. Specifications: Parameter Value SoC ESP32-C6 RISC-V core, Wi-Fi 6 + BLE 5 + 802.15.4 (Thread/Zigbee) Module ESP32-C6-WROOM-1(U) module with Xtensa® LX7 core — (note: WROOM-1 module actually uses a RISC-V core per Espressif docs; core architecture varies by source — verify against your datasheet) Flash Memory 16MB SPI Flash (N16) Wireless Wi-Fi 6 (IEEE 802.11 b/g/n), Bluetooth LE 5.0 (including BLE audio), Zigbee (3.0), Thread (1.3) GPIO 23 GPIO pins broken out across 32 pins (2.54mm pitch), plus 3V3, 5V, and GND for power ADC 7 ADC-capable pins for sensors and battery monitoring USB USB Type-C to UART port for power supply and communication with the ESP32-C6 chip Power Regulation Operates at 3.3V; onboard regulator converts 5V USB supply to 3.3V output Board Version v1.2 Onboard Features: USB-to-UART bridge for flashing and serial monitoring Boot and Reset buttons Pin headers on both sides for breadboard-friendly prototyping Onboard status LED All GPIOs are 3.3V only (not 5V tolerant) — level shifting required for 5V peripherals Ideal For: IoT and smart-home development, matter/Thread/Zigbee mesh networking projects, low-power sensor nodes, and applications requiring larger flash for OTA firmware updates or local data storage. Package Includes: 1x ESP32-C6-DevKitC-1 v1.2 (N16) Development Board
