Product details

📝 Product Description The ZK-PP2K DC Motor Tester is a versatile PWM controller designed for precise control, testing, and automation of DC motors in various electronics and robotics projects. Supporting up to 8A output current and a wide voltage range of 5–30V , this module offers both PWM Mode and Pulse Mode for customized motor behavior. Users can easily adjust frequency , duty cycle , number of pulses , and delay intervals via an onboard screen and buttons. A rear JST-XH 2p connector allows for external stop button integration (button not included), adding more control options to your setup. Whether you're developing automation systems, testing gear motors, or building robotic projects, the ZK-PP2K is a compact, high-precision controller that delivers reliable performance. 🔧 Key Features ⚡ Input Voltage : 5V to 30V DC 🚗 Max Output Current : 8A ( cooling may be needed above 5A or 20kHz ) 🔁 Operation Modes : PWM Mode – Set frequency (1Hz–150kHz) and duty cycle (0–100%) Pulse Mode – Set motor ON/OFF time, number of pulses, and startup delay 📺 Onboard Display & Buttons – Easy adjustment of parameters 🔘 External Stop Button Support – JST-XH 2-pin connector on PCB 🌐 Compact & Durable Design – Ideal for embedded systems & test benches 📏 Operating Temp : -20°C to 85°C 🌍 Applications DC motor speed testing and adjustment Gear motor and actuator testing Robotics and automation systems DIY electronic controls Industrial motor diagnostics 📋 Technical Specifications: Attribute Details Input Voltage 5 – 30V DC Output Voltage 5 – 30V DC (same as input) Max Output Current 8A (cooling recommended >5A) Frequency Range 1Hz – 150kHz Frequency Accuracy ±2% Duty Cycle 0 – 100% Signal Type Square Wave (some distortion at high frequency) Stop Button Connector JST-XH 2-pin Operating Temperature -20°C to +85°C 📦 Package Includes 1 × ZK-PP2K DC Motor Tester / PWM Controller
