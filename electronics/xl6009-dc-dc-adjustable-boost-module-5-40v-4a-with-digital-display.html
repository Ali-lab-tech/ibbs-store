Product details

Product Description XL6009 is a 4A switch current high-performance boost ( BOOST ) module. This module uses the second-generation high-frequency switching technology XL6009E1 as the core chip, and its performance far exceeds that of the first-generation technology LM2577. The XL6009 booster module has a lower cost and better performance, and the LM2577 module is about to be eliminated. Application range: This module can be used in the boost field where the output voltage is higher than the input voltage, such as batteries, transformers, DIY adjustable power supplies, 24V car notebook power supplies, industrial equipment step-down, 9 to 12V, 12V to 18V, 18V to 24V, etc. Wiring Instructions IN +: Input positive IN-: Input negative pole OUT + : output positive OUT-: output negative pole Features Ultra-wide input voltage 3V~32V ( the booster below 5V works normally, but the digital tube does not work), the best working voltage range is 5~32V. Super wide boost output voltage 5V~40V. Built-in 4A high-efficiency MOSFET switch tube, making the efficiency up to 94%( LM2577 current is only 3A ). An ultra-high switching frequency 400KHz can achieve very good results with a small-capacity filter capacitor, the ripple is smaller and the volume is smaller. (The frequency of LM2577 is only 50KHz ). With the input display indicator and output display indicator, the IN indicator lights when the digital tube displays the input voltage, and the OUT indicator lights when the digital tube displays the output voltage. With overheat protection and short circuit protection Physical Attributes Dimension - 65mm*39mm*14mm Weight - 40g Package Includes 1 x XL6009 DC-DC Adjustable Boost Module 5-40V 4A with Digital Display
