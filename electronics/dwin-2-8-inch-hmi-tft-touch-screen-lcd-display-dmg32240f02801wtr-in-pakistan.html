Product details

DWIN 2.8 Inch HMI TFT Touch Screen LCD Display DMG32240F028_01WTR This DWIN 2.8 inch SMART Screen is quite useful and is full features load SMART screen. It is called a SMART screen because it comes with UI development Software pre-installed from the manufacturer which gives users great and useful tools to develop their own UI with great features. One can design UI Such as a button, slider, Graph, Text Display, etc on their own. User can Develop their own UI Using the software provided and pre-installed for it called TA / DGUS II ( DGUS II pre-installed). Also, it is supported with RGB colors and 16.7M colors. It is also equipped with 300 nit brightness which makes it visible in daylight too. It is compatible with All micro-controller Boards like Arduino, Raspberry, and many more… which can interface with I2C communications.
