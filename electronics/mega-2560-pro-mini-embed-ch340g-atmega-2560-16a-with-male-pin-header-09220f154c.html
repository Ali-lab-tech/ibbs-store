Product details

Mega 2560 PRO MINI it is version PRO of Arduino Mega 2560 R3. Built on the Atmel ATmega2560 microcontroller. The board has compact size 38×52mm. It is a good solution, to make your final project on solder prototyping board. You can find all pinouts on board: digital's I/O - 70 and analog's input - 16. Mega 2560 PRO MINI as functionality similar to the Arduino Mega 2560. It is built on MINI board, but the same stable, and uses the original chips ATmega2560 (16MHz). The board has a USB interface, based on USB-serial converter CH340G. For connecting to PC, pls use the Micro USB cable. You can supply power to board through the power pin-headers or USB interface. Output current for 5V version - about 800mA, for 3.3V version - about 800mA (Please note that the higher the input voltage the lower the outgoing current). That will provide a reliable power most of your initial projects. On the picture, you can see the real size of this board, compare with the size of Mega Rev3.
