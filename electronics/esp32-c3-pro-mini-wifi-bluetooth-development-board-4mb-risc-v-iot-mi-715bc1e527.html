ESP32-C3 PRO MINI WiFi Bluetooth Development Board The ESP32-C3 PRO MINI is a high-performance IoT development board based on the Espressif ESP32-C3 WiFi and Bluetooth dual-mode chip. Featuring a 32-bit RISC-V single-core processor running up to 160MHz with built-in FPU for enhanced computing performance, this ultra-compact board is ideal for smart home devices, wireless sensors, wearable technology, and embedded IoT projects. Key Features ESP32-C3 32-bit RISC-V Processor: Single-core CPU running up to 160MHz with built-in FPU (Floating Point Unit) Dual Wireless Connectivity: WiFi 802.11 b/g/n (2.4GHz) and Bluetooth 5.0 (LE) support 4MB Flash Memory: Ample storage for firmware and data logging Ultra-Low Power: Deep sleep power consumption ~43µA, perfect for battery-powered applications Rich I/O Options: 11 GPIO pins (PWM supported), 4 ADC channels, I2C, SPI, 2× UART interfaces Dual Antenna Design: Ceramic antenna + IPEX antenna connector for flexible wireless deployment Compact Form Factor: Ultra-small 22.52 × 18mm single-sided SMD design, ideal for wearables Onboard Components: Blue LED (GPIO8), Reset and Boot buttons included Technical Specifications Parameter Description Chip Model ESP32-C3FH4 / ESP32-C3FN4 CPU 32-bit RISC-V Single Core Frequency Up to 160 MHz WiFi 802.11 b/g/n (2.4GHz) Bluetooth Bluetooth 5.0 (LE) Flash 4MB SRAM 400KB ROM 384KB GPIO 11 (PWM Supported) ADC 4 Channels Interfaces 1× I2C, 1× SPI, 2× UART Dimensions 22.52 × 18 mm Deep Sleep Current ~43 µA Applications IoT sensor nodes and wireless data logging Smart home automation systems Wearable devices and fitness trackers Robotics and embedded systems Student and university electronics projects Low-power battery-operated devices Why Choose ESP32-C3 PRO MINI? This development board offers powerful RISC-V processing, WiFi + Bluetooth connectivity, and ultra-low power consumption in a compact size—making it the ideal choice for IoT developers, students, and makers working on wireless embedded projects.
