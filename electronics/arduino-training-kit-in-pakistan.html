Product details

The Mikroduino Nano V2 is an all-in-one Arduino Nano development shield designed for students, hobbyists, and electronics enthusiasts who want to learn and prototype without messy breadboard wiring. Made in Pakistan by Mikrotronics, this board brings everything you need onto a single, well-organized PCB. 🔌 Power Supply Accepts DC 9–12V input via barrel jack Onboard 7805 voltage regulator for 5V output LM1117S-3.3 regulator for 3.3V output Reverse polarity protection via 1N4007 diode Dedicated 9V, 5V, and 3.3V breakout headers 🧠 Core Controller Compatible with Arduino Nano (plugs into onboard socket) Full access to all Digital (D0–D13) and Analog (A0–A7) pins via labeled headers 💡 Onboard Components 8x Red LEDs (D0–D7) with 220Ω current-limiting resistors Piezo Buzzer for audio feedback LDR (Light Dependent Resistor) with 10k pull-down Potentiometer (10k) for analog input testing 4x Tactile Push Buttons (B1–B4) 📡 Communication & Peripherals HC-05 Bluetooth Module header (with RXD/TXD) DS1307 RTC (Real-Time Clock) module socket with I2C pins DHT11 temperature & humidity sensor header IR Sensor breakout header MAX7219 LED driver header (SPI) OLED Display header (I2C) I2C LCD header SPI and I2C breakout headers UART header for serial communication 📐 Form Factor Compact PCB with clearly labeled silkscreen Mounting holes for enclosure or stand-off installation Clean layout with grouped and labeled expansion headers ✅ Who Is It For? Engineering students learning Arduino programming Teachers setting up electronics labs Makers prototyping IoT and embedded projects Anyone who wants a plug-and-play Arduino learning platform
