Product details

The HiATA Arduino Mega Bootloader Burner is designed to quickly and easily program Arduino Mega boards with the latest bootloader. This offline standalone ISP programmer ensures trouble-free programming, allowing you to get your project up and running faster. This is a bootloader burner which works standalone without any computer connection and program Arduino Mega R3 Board IC's, including its programmer ic which is ATMEGA16U.
