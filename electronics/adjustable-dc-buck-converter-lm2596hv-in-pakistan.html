Product details

LM2596HV module is a high input voltage version of the LM2596 Module. The LM2596HV module is a DC to DC converter buck converter module with an input voltage range of 4.5 volts to 50 volts and an output of 1.25–35 V. This output is variable and can be varied using the on-board multi-turn potentiometer. Buck Converter Module is capable of driving a load up to 3A with high efficiency. When the output current required is greater than 2.5A(10W) an external heatsink is suggested.
