Product details

The FNIRSI LC1020E is a handheld digital LCR bridge with a 4.5-digit display and 0.3% basic accuracy. It measures L, C, R and Z with X, D, Q, θ and ESR as secondary readings, and picks the component type automatically. Test frequency runs from 100Hz to 100kHz with 0.1V, 0.3V or 0.6V test levels and selectable bias. With both 3-terminal and 5-terminal (4-wire Kelvin) inputs, open/short calibration and tolerance sorting, it suits incoming inspection as well as repair. Key Features 🎯 0.3% basic accuracy 4.5-digit main and secondary readings 🎚️ 100Hz, 120Hz, 1kHz, 10kHz, 100kHz 0.1 / 0.3 / 0.6V test levels 🔍 Automatic R / L / C recognition with series/parallel models 🔌 3-terminal and 5-terminal Kelvin inputs Kelvin clip included ✅ Sorting with 0.1 – 99.9% tolerance and pass/fail counts 🔋 3.7V 3000mAh battery USB-C virtual serial port Technical Specifications Test frequency 100Hz, 120Hz, 1kHz, 10kHz, 100kHz Basic accuracy 0.3% Display 2.8" TFT, 4.5 digits Main parameters AUTO / R / C / L / Z Secondary parameters X / D / Q / θ / ESR Range L: 0 – 100H, C: 0 – 100mF, R: 0 – 10MΩ Test level 0.1V, 0.3V, 0.6V Internal bias 0.0V, 0.5V Output impedance 100Ω Interface USB Type-C (virtual serial port) Battery 3.7V 3000mAh What's in the Box 1 × LC1020E LCR meter 1 × data cable 1 × shorting plate 1 × Kelvin test clip 1 × pair of test leads (red, black) 1 × user manual
